# Synthetic API fixture

`participation-time-v5.json` is the relevant UI subset of the synthetic backend/API fixture produced from the participation timing fix at `55adcd3` (algorithm `focus-group-local-5`). It includes four fictional speaker IDs: A observed 10 seconds; B observed 2 seconds plus a missing turn; C entirely missing; Z an observed zero. Overview/group/speaker numbers and coverage are copied without recalculation. The original time bins are included so the same fixture also checks coverage-aware timeline rendering. No user data or application database is included.

Original synthetic fixture SHA-256: `48f109c6505bf89a7dc9d193f32f03584991a0aba04c8b8f0afd78fe6b40ac9d`. The producer retains the full original in the session evidence as `analysis-recovery-review/speaker_timing_ui_fixture.json`.

`participation-all-missing-v5.json` is the corresponding synthetic backend subset with A/B both untimed. The backend supplies one zero-filled 0–300 second bin despite timed_turn_count=0; UI tests must not present this placeholder as measured zero. Original full fixture SHA-256: `de8ff504565d2b6cd8bfcefb1512fae39722bcacabfe5bc4e040a08930c4bb0e`.


`remaining-timing-v7.json` is a minimal projection of seven synthetic Flask analysis/job response pairs captured from backend `a383df17d368e79e696cf6e51dd4808f15b5f719` (algorithm `focus-group-local-7`). Cases are all unknown, partial two turns/ten known seconds, true zero at zero, true zero at ten, empty, ordinary positive, and an excluded untimed source turn. The last case distinguishes all-source endpoint coverage from included speaking-time coverage. Calculated fields, coverage, version, and raw segments are copied without recalculation. Unused response fields and temporary output paths are omitted.

The only value override is `analysis.executed=true`, replacing the source API's `false` so the existing results view is rendered. This is display-only scaffolding, not evidence that the analysis pipeline executed, and not an unmodified API-to-browser E2E test. The original response remains in the session evidence as `analysis-recovery-review/timing-api-full-a383df1.json`, generated by `emit_timing_api_fixtures.py`; its hash and the projection hash are recorded in `remaining-timing-provenance.json`. Tests use the actual shipped HTML/scripts and DOM event wiring, not browser rendering or native input.


`timing-projection.json` keeps thirteen synthetic full-job response subsets from backend/UI `97847d12715493fcabd7368d1851167fb7cd577a`. It copies `segments`, `segment_timings`, IDs, profiles and duration coverage without altering values/types or execution flags. Numeric ASCII, surrounding whitespace, exponent, fullwidth, Arabic, underscore, string/numeric zero, ordinary number, invalid/unknown/above-limit, and two-string-turn cases come from actual Flask responses. Original full responses, analysis/list cross-checks, raw segments, and expected bounds remain in `analysis-recovery-review/numeric-projection-api-97847d1.json`, created by `emit_numeric_projection_fixtures.py`; source/projection hashes are in `timing-projection-provenance.json`. Stale and malformed derivatives are declared inside the tests. These are offline DOM event/Save tests; they do not certify native browser input, media seeking, layout or AT.


`import-timing-markers.json` copies six complete parsed job DTOs from ordinary synthetic output-JSON imports at `5d5c59456fc24e58e32d3ec278a7beb7dc4f3e13`. Each has an A candidate with an empty array/object `time_unknown` marker and numeric, string, or true-zero bounds, plus a known five-second B reference. The raw marker and its source-binding marker are separate parsed containers. Full DTO values are unchanged; expected measurements and original raw-DB hashes are retained. Original import files and DB JSON were checked unchanged by the independent producer. `import-timing-markers-provenance.json` records source/projection hashes and candidate UI `4c319833d948c4b6c0f1ae50251e48b21e4815d9`.

The test-owned response for the incidental meeting-Obsidian status GET is isolated from timing assertions. Save tests inspect actual handler payloads and return synthetic responses; they are not a live browser-to-database write test. Real time-change events exercise redraw and stale timing bindings. Nonempty and type-changed markers are explicit negative derivatives. The unchanged audio/evidence predicate remains false for these containers; no actual media playback is claimed.
