# 動画入力・実行設定画面の確認項目

リポジトリのルートで実行します。

```powershell
.\scripts\test_video_input_settings.ps1
```

Jev にも確認結果の分類を依頼する場合:

```powershell
.\scripts\test_video_input_settings.ps1 -ReviewWithJev
```

ブラウザー QA には Playwright が必要です。未導入の場合、先に次を実行します。

```powershell
.\.venv\Scripts\python.exe -m pip install playwright
```

Jev は設定済み TypeSafe System One API を通じて PASS / FAIL / INSUFFICIENT を選びます。コード変更、ブラウザー操作、修正手順の生成は行いません。結果は参考分類として扱い、成否はローカルテストで判断します。

## 今回の実行結果（2026-09-23）

- `tests.test_ui_defaults`: 15件成功。
- Playwright / Edge: 1440 × 900、1280 × 800、390 × 844 で横はみ出しなし。1280 × 800 では開始ボタンの下端が786.3pxで画面内に表示され、390 × 844 でも横はみ出しなし。設定詳細は初期状態ですべて閉じた状態。
- CPU / GPU と認識モデルの切り替えが要約に反映される。AI仕上げ「しない」では使用モデルなしと表示し、テスト用 OpenAI モデル選択時は実行状態とモデル名を表示する。設定再読込後も明示した「使用しない」を維持する。
- スマートフォンで段階移動、ファイルのドラッグ＆ドロップ、キーボードによる設定表示を確認。
- 無効ファイルのエラー表示、有効な動画選択、認識と AI 仕上げの不正設定を再表示して送信を止めること、モックへの1回のジョブ送信と動画付きペイロードを確認。
- 文字サイズ: 設定名・値15px、補足文13px。
- Jev（`jev-1.13.0`）: PASS 0.56、FAIL 0.39、INSUFFICIENT 0.04。Jev は構造化判定のみ。

スクリーンショットと結果 JSON は `output/design/video-input/` に保存します。今回の画像は `final-1440x900.png`、`final-1280x800.png`、`final-390x844.png`、スマートフォン操作後の画面は `final-mobile-settings.png` と `final-mobile-start.png` です。

## 手動確認項目

小さなテスト動画を使い、1440 × 900、1280 × 800、390 × 844 で確認します。

- どの画面幅でも横方向にはみ出さず、デスクトップの初期画面で開始ボタンが見える。
- ファイル選択ボタンとドラッグ＆ドロップが使え、未対応ファイルには理由が表示される。選択したファイル名と情報も表示される。
- 3段階の進行表示をポインターとキーボードで操作でき、ファイルと設定は段階を移動しても保持される。
- 実行設定の詳細は初期状態ですべて閉じ、開閉や変更が要約に反映される。
- 文字起こし装置と話者分離装置を CPU / GPU に切り替え、認識モデル名と要約の表示が一致する。
- AI仕上げを「しない」と「する」に切り替え、使用モデルなし／選択したサービスとモデル名が実際の設定に一致する。設定を再取得しても明示した「使用しない」が維持される。
- `min_speakers=0` などの不正設定で実行した場合、その設定欄を再表示して送信しない。
- 正しい入力での送信は1回だけ行い、モックされたバックエンドが期待するジョブ情報を受け取る。
- ファイル選択、設定の開閉、段階の移動だけではアップロードやジョブ作成を送らない。

実際の Obsidian Vault や個人動画は使わず、ジョブ送信確認には一時データ領域とモックを使います。
