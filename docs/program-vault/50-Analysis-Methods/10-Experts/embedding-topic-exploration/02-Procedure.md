# 埋め込みによるテーマ探索の専門家：手順

計算の定義は既存の手法ノート [[50-Analysis-Methods/02-Semantic-and-Audio/01-Transformer-Topics]]（`transformer_topics`）による（[実装判断]）。

## 手順と各段階の確認事項

| 段階 | 内容 | 担当 | 確認事項 |
| --- | --- | --- | --- |
| emb-p1 | 対象と文脈補完 | コード | 意味のある発話だけを選び、短い断片には同じ話者・3秒以内の隣接発話を文脈として加える。除外数と文脈補完数を記録する |
| emb-p2 | 埋め込みとクラスタリング | コード | `intfloat/multilingual-e5-small`（384次元）、K-means（`random_state=42`、`n_init=10`）。テーマ数の指定がなければ、最小クラスタサイズを満たす候補からコサインのシルエットが最大の数を選ぶ。[文献] 平均シルエット幅でクラスタ数を選べる可能性（Rousseeuw 1987、要旨） |
| emb-p3 | 原文での確認 | 研究者 | 仮ラベルは内容語からの仮のもの。[文献] 自動的な方法は精読の代わりにならない（Grimmer & Stewart 2013、要旨） |
| emb-p4 | 判断と報告 | 研究者 | クラスタの併合・分割・除外は研究者が承認する（既存ノート） |
| emb-p5 | 手動テーマの定義 | 研究者 | 手動で割り当てる場合は、テーマの見出しと、手がかり語かシード発話を定義して保存する（[実装判断]） |
| emb-p6 | 手動テーマへの割り当て | コード | 定義から作ったテーマのベクトルへ最近傍で割り当て、しきい値未満は未割当にする。未割当と境界例は研究者が原文で確認する（[実装判断]） |

## 判断に迷いやすい点

- [実装判断] シルエットの値が低い、クラスタが少数、候補の間の差が小さい場合は、人による見出しの確認を必須にする（既存ノート）。
- [整理] 司会者の質問が似た言い回しで繰り返されると、司会者の発話だけのクラスタができることがある。話者分布を確認する。
- [実装判断] 相づちは時刻と短い文の辞書からの候補で、応答先は時系列上の推定。賛同とは断定しない（既存ノート）。
- [実装判断] 手動のテーマは研究者の見出しであり、割り当ては最近傍の候補である。しきい値（既定はなし）と、上位2テーマの差が小さい境界例の目安は実装上の判断で、検証していない。

## 典型的な失敗と修正

| 失敗 | 修正 |
| --- | --- |
| クラスタの仮ラベルをテーマ名として報告する | 代表発話と外れ値を読み、テーマ分析の手順で別途テーマを生成する |
| シルエットが高いのでテーマは妥当とする | シルエットは幾何的なまとまりの指標で、意味の妥当性は原文で確認する |
| 話者の偏りでできたクラスタを内容のテーマとみなす | 話者分布を見て、クラスタの成り立ちを確認する |

## 結果のまとめ方

モデルと条件 → クラスタの一覧と仮ラベル → 代表発話・外れ値 → 話者分布と時間推移 → 研究者の確認の記録 → 限界。
