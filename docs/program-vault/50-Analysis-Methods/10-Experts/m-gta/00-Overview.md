# M-GTAの専門家：概要

専門家定義：[[50-Analysis-Methods/10-Experts/m-gta/01-Expert]]

## この専門家が答える問い

- 人間の認識や行為が、社会的相互作用の中でどう変化していくか（プロセス）を、データに基づく概念とカテゴリーで説明したい。ヒューマンサービス領域など、現象がプロセス的な性格を持つ場合に適するとされる。[文献] [[50-Analysis-Methods/20-Literature/LIT-kinoshita-2007-mgta|木下 2007]]
- 限定された範囲（分析焦点者と分析テーマ）で一般化しうる知識を生成したい。[文献] [[50-Analysis-Methods/20-Literature/RES-mgta-society-official|M-GTA研究会]]

## この専門家が答えない問い

| 問い | 移す先・理由 |
| --- | --- |
| 類型ごとの人数や頻度を示したい | M-GTAでは度数的な結果表示は成り立たないとされる（木下 2007） |
| 共通する意味のパターンの解釈 | [[50-Analysis-Methods/10-Experts/thematic-analysis/01-Expert\|テーマ分析]] |
| 少量のデータの段階的な理論記述 | [[50-Analysis-Methods/10-Experts/scat/01-Expert\|SCAT]] |

## 流派

[文献] グラウンデッド・セオリー・アプローチは4つのタイプに分化しており、M-GTAはその1つとされる（木下 2007、2節）。M-GTAは切片化という技法を用いない点で、オリジナル版、ストラウス・コービン版、グレーザー版、シャーマズの試みと距離をおく（M-GTA研究会のページ）。

| 流派 | 切片化 | この定義での扱い |
| --- | --- | --- |
| M-GTA（木下） | 用いない。分析テーマと分析焦点者を視点にデータに着目する | 既定 |
| 切片化を用いる他のGTA | 用いる | 対象外（手順を混ぜない） |

## 関連する実装

- [実装判断] Gurumojiには分析テーマ・分析焦点者・分析ワークシートの専用の欄がない。分析テーマは研究質問、概念はコードブックのコード（定義を含む）、理論的メモは分析メモで代用する。
