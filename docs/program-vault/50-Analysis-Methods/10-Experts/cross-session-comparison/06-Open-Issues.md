## 知識が不足している点

- 複数のフォーカスグループを比較する分析の方法論文献を確認していない。

## 実装上の課題

- 会話の数が少ない比較で推測統計を行わないことは、専門家定義の禁止事項で示すだけで、画面上の制限はない。
