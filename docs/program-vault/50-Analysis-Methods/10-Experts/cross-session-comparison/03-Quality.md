# 会話間比較の専門家：判断基準と品質確認

## 判断基準

- [文献] 明確な区別のあるものを比較し、比較対象は適度に具体的な同一の概念に含まれることが望ましい（樋口 2017、4節、p.347）。
- [文献] 設計を最適化するには、1つの対象からの観測を増やすより、真に独立な観測を増やすことがほぼ常に重要とされる（Aarts et al. 2014、要旨）。

## アプリが判定する項目と人が確認する項目

| ID | 内容 | 判定 |
| --- | --- | --- |
| cmp-q1 | 比較する会話が2回以上 | コード（`comparison_sessions_min`、保存時の比較の件数で判定） |

| cmp-q3 | 率の違いをグループの性質と断定していないか | 研究者 |
