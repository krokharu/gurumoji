# 音声感情推定の専門家：手順

計算の定義は既存の手法ノート [[50-Analysis-Methods/02-Semantic-and-Audio/02-Audio-Emotion]]（`audio_emotion`）による（[実装判断]）。

## 手順と各段階の確認事項

| 段階 | 内容 | 担当 | 確認事項 |
| --- | --- | --- | --- |
| ser-p1 | モデルと条件 | コード | モデル名、Hugging Faceのリポジトリ（`imprt/kushinada-hubert-large-jtes-er` など）、fold、主ラベルのみか確信度があるか。[文献] ライセンスはApache-2.0、ファイルの取得には利用条件への同意が必要（モデルカード） |
| ser-p2 | 推定と集計 | コード | 話者分離後の各発話音声を切り出して推定し、ang・hap・sad・neuの主ラベルを発話へ保存する。話者・モデル・ラベル別に件数と発話秒数を集計する。確信度は取得できる場合だけ保持し、ない場合は `null` |
| ser-p3 | 上流の誤差の確認 | 研究者 | 音声区間の切り出し、話者分離、雑音が上流の誤差の源になる。短い区間、重なり、音質の不良、未推定を確認し、欠測を0件に混ぜない。[文献] 話者分離の誤りと重なり（Park et al. 2022） |
| ser-p4 | 聴取確認と報告 | 研究者 | 必要な箇所を聴いて確認し、自動推定と手修正を区別する。[整理] 表出から感情状態を推論する不確かさ（Barrett et al. 2019は顔の動きについての総説） |

## 判断に迷いやすい点

- [実装判断] 両モデルを使った場合は、一致・不一致を独立に表示し、片方のラベルで上書きしない（既存ノート）。
- [整理] 「neu」の多さは、感情が表出されていないことや、モデルが判断できないことを含みうる。平静や無関心と解釈しない。

## 典型的な失敗と修正

| 失敗 | 修正 |
| --- | --- |
| 「参加者Aは怒っていた」と書く | 「音声モデルが ang と推定した発話が n 件」と、モデル名とともに書く |
| モデルカードの正解率（0.8477）をこの会話の正確さとして示す | 評価条件（JTES）を示し、この会話での正確さは聴取確認でしか分からないと書く |
| 未推定の発話を集計から黙って落とす | カバー率と未推定の件数を示す |

## 結果のまとめ方

モデル・版・学習データ・評価条件 → 集計 → カバー率と未推定 → 聴取確認の記録 → 限界。
