# テーマ分析の専門家：概要

専門家定義：[[50-Analysis-Methods/10-Experts/thematic-analysis/01-Expert]]

## この専門家が答える問い

- 研究質問に関して、データセットに共通する意味のパターン（テーマ）は何か。テーマは研究者の解釈によって生成される。[文献] [[50-Analysis-Methods/20-Literature/LIT-braun-clarke-2006-thematic|Braun & Clarke 2006]]、[[50-Analysis-Methods/20-Literature/LIT-oka-2022-reflexive-ta-ja|岡ほか 2022]]
- テーマを、明示的な意味（意味的水準）で捉えるか、背後の考え方（潜在的水準）で捉えるか。[文献] Braun & Clarke 2006

## この専門家が答えない問い

| 問い | 移す先 |
| --- | --- |
| 意味の近い発話の自動的なまとまり | [[50-Analysis-Methods/10-Experts/embedding-topic-exploration/01-Expert\|埋め込みによるテーマ探索]]（テーマ分析の代替ではない） |
| 定義・規則を持つカテゴリーへの体系的な整理と、コーダー間の一致 | [[50-Analysis-Methods/10-Experts/qualitative-content-analysis/01-Expert\|質的内容分析]] |
| その場の応答による意見の形成 | [[50-Analysis-Methods/10-Experts/focus-group-interaction/01-Expert\|相互作用分析]] |
| テーマの頻度・代表性の提示 | この手法（再帰的TA）の目的と合わない |

## 流派

[文献] Braun & Clarkeはテーマ分析を、コーディングの信頼性型、コードブック型、両研究者の再帰的TAの3つのタイプに分ける（岡ほか 2022、p.146）。TAには手続きや哲学の異なる多くの形があり、それを区別せずに品質基準を当てはめることが問題とされる（[[50-Analysis-Methods/20-Literature/LIT-braun-clarke-2021-one-size|Braun & Clarke 2021]]、要旨）。

| 流派 | 特徴 | この定義での扱い |
| --- | --- | --- |
| 再帰的TA | 研究者の主観的な分析スキルを使う解釈的なアプローチ。評定者間の一致、テーマの飽和、コードブックを使わない（岡ほか 2022） | 既定 |
| コードブック型TA | コードブックとコーディング枠組みを使う（岡ほか 2022） | 流派として記録のみ |
| コーディングの信頼性型TA | コーディングの信頼性の測定を行う（岡ほか 2022） | 流派として記録のみ |
