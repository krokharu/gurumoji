# SCATの専門家：判断基準と品質確認

## 判断基準

- [文献] ストーリーラインで〈4〉を使わないと、〈4〉まで分析した意味が薄れ、ストーリーラインの妥当性を担保するものがなくなるため、使った〈4〉に下線を引いて漏れがないことを確認するよう勧める（大谷 2011、4.8節）。
- [文献] 〈4〉に文を書くとSCATの性能が発揮されないとし、概念（名詞または名詞句）を書くよう求める（公式ページ）。
- [文献] すぐれた分析には、関連する文献を参照しながら分析を見直すことが必要（大谷 2011、p.158）。
- [文献] 理論記述の「理論」は、普遍的で一般的な原理ではなく、このデータから言えることで、個別性・具体性・多様性に即した質的研究ではかえって意味がある（大谷 2011、p.159）。

## アプリが判定する項目と人が確認する項目

SCATの品質は分析者のコーディングと記述の吟味によるため、コードで判定する品質項目は置かない（[実装判断]）。`scat-q1`〜`scat-q5` はすべて研究者が確認する項目で、アプリは確認済みと表示しない。適用条件では、発話数の目安（300件）だけをコードで判定する。

## ほかの手法との違い

[整理] SCATは〈1〉〜〈4〉の段階を分析者が明示的に書くことで分析の過程を示す。テーマ分析の再帰的TAのように解釈の吟味を中心にする点は近いが、段階ごとの記入欄と、ストーリーラインで〈4〉をすべて使うという確認方法を持つ点が異なる。
