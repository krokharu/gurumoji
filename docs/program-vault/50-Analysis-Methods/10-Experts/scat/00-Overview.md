# SCATの専門家：概要

専門家定義：[[50-Analysis-Methods/10-Experts/scat/01-Expert]]

## この専門家が答える問い

- 1つのケースのデータや、比較的小規模の質的データから、明示的な手続きで段階的にコーディングし、ストーリーラインと理論記述（このデータから言えること）まで進めたい。[文献] [[50-Analysis-Methods/20-Literature/LIT-otani-2011-scat|大谷 2011]]
- 分析の過程を、〈1〉〜〈5〉のマトリクスとして示したい。

## この専門家が答えない問い

| 問い | 移す先 |
| --- | --- |
| 大量のデータの全体像を把握したい | [[50-Analysis-Methods/10-Experts/quantitative-text-analysis/01-Expert\|計量テキスト分析]]（探索） |
| 複数のケースを行列で比べたい | [[50-Analysis-Methods/10-Experts/framework-method/01-Expert\|フレームワーク法]] |
| 変化のプロセスを説明する理論を作りたい | [[50-Analysis-Methods/10-Experts/m-gta/01-Expert\|M-GTA]] |
| 他のデータにも当てはまる普遍的な法則を示したい | この手法の理論記述の目的と合わない（大谷 2011） |

## 関連する実装

- [実装判断] Gurumojiには〈1〉〜〈5〉のマトリクスを記録する機能はない。セグメントの目安として発話IDを使い、マトリクスは研究者が外部の表などで作る。
