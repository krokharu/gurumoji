# SCATの専門家：適用条件と限界

## 入力データの条件

| 条件 | 満たさない場合 | 根拠 |
| --- | --- | --- |
| 研究質問がある | 要確認（`scat-a1`） | [実装判断] |
| 分析できる発話がある | 分析を始めない（`scat-a2`） | [実装判断] |
| 発話が300件以下 | 要確認（`scat-a3`） | [文献] 小規模データにも適用できる手法（大谷 2011）。300件は[実装判断] |
| セグメントが1トピック単位 | 研究者が確認（`scat-a4`） | [文献] 大谷 2011、4.2節 |
| 概念的枠組みと関連文献 | 研究者が確認（`scat-a5`） | [文献] 大谷 2011 |

## この手法の結果から言えないこと

- 理論記述を、ほかのデータにも当てはまる一般法則として述べること（[文献] 大谷 2011、p.159）。
- 分析者が書いていない〈2〉〜〈4〉を含む結果を、SCATの分析結果とすること（[実装判断]）。

## グループインタビューでの注意

- [整理] SCATの例は1人の語り手と聞き手の面接で、聞き手と語り手の発話を区別しやすくしている（大谷 2011の分析例）。グループインタビューに使う場合は、話者の区別と、応答の文脈がセグメントの区切りで失われないかを確認する。
- [実装判断] 司会者の質問をセグメントに含める場合は、〈1〉の注目すべき語句として参加者の語句と混ぜない。
- [整理] 複数の参加者の語りを1つのストーリーラインにまとめると、個人差や意見の違いが見えにくくなる。必要に応じて相互作用分析と並べる。
