# 計量テキスト分析の専門家：適用例

[[50-Analysis-Methods/20-Literature/LIT-higuchi-2017-khcoder|樋口 2017]] が概観した応用研究（原典は未読。樋口の記述の範囲で記録する）。

| 応用研究（樋口 2017の節） | データ | 樋口 2017が示す要点 |
| --- | --- | --- |
| Twitterの発信内容（3.2.1節） | 選挙の候補者のツイート | 研究の問いが明確で、先行研究に倣った比較の枠組みがあった |
| Twitterの語られ方（3.2.2節） | 特定の民族についてのツイート | 理論に基づく演繹的な方針と、比較による帰納的な探索を併用し、コーディングルールを公開した |
| アンケート自由回答（3.4.1節） | 高校生の調査 | 選択肢型の質問の分析で問いを明確にしてから自由回答を分析した |
| インタビュー記録（3.4.2節） | 看護師へのインタビュー | 腰痛の有無の群で共起ネットワークを比べ、質的な分析の道しるべにした |
| 会議録（3.5節） | 国会の会議録、模擬裁判の評議 | 事前の歴史分析に基づくコーディングルール、領域の造詣による特徴語の読み取り |

## 確認できていないこと

- 上記の応用研究の原典は読んでいない。
- フォーカスグループの逐語録に計量テキスト分析を適用した研究の本文は確認していない（樋口 2017は、グラウンデッド・セオリーと組み合わせたフォーカスグループの分析例を参考文献に挙げている）。
