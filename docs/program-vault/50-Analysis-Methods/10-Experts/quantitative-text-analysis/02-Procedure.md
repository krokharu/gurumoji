# 計量テキスト分析の専門家：手順

## 手順と各段階の確認事項

| 段階 | 内容 | 担当 | 確認事項 |
| --- | --- | --- | --- |
| qta-p1 | 問い・比較の枠組み・注目概念 | 研究者 | 分析を始める前に具体的に設定する（[文献] 樋口 2017、4節、p.346） |
| qta-p2 | 解析条件の固定 | コード | 解析器、辞書、分割モード、ストップ語を結果と一緒に保存する（[実装判断]、既存ノート [[50-Analysis-Methods/01-Text-and-Context/03-Morphology]]） |
| qta-p3 | 頻度・共起・特徴語 | コード | 多変量解析による要約の段階では、語を逐一選ぶ手作業を避け、分析者の理論や問題意識による偏りを減らす（[文献] 樋口 2004、3.1節、p.105） |
| qta-p4 | 比較の枠組み | 研究者 | 明確な区別のあるものを比べ、比較対象が適度に具体的な同一の概念に含まれるようにする（[文献] 樋口 2017、4節、p.347） |
| qta-p5 | 原文への往復 | 研究者 | 計量的分析の結果を参考にもとの文章を質的に解釈する（[文献] 樋口 2017、2.1節） |
| qta-p6 | 規則の記録 | 研究者 | コーディング規則を明示・公開すると、分析の信頼性と分析概念の汎用性が高まる（[文献] 樋口 2017、3.2.2節、樋口 2004） |

## Gurumojiの計算との対応

| 手法ID | 計算の内容 | 読み方 |
| --- | --- | --- |
| `lexical_frequency` | 内容語のTF、DF、TF–IDF | TF（延べ）とDF（語を含む発話数）を混ぜない（既存ノート） |
| `cooccurrence` | 同一発話内の語ペア、Jaccard、Dice | 同じ発話にあることは概念的な関係を意味しない |
| `speaker_characteristics` | 話者ごとの発話出現率と他話者の率の差 | 検定ではない。少数発話の話者は不安定 |
| `kwic` | 検索語の前後40文字と前後の発話 | 語義、否定、引用、言い直しを確認する |

## 判断に迷いやすい点

- [文献] 帰納的に分析すれば必ずうまくいくとは限らず、解釈に十分な時間と、言葉の違いから背後の状況を推論できる当該分野の造詣が必要とされる（樋口 2017、p.346）。
- [整理] グループインタビューでは、司会者の質問に含まれる語が参加者の語の頻度や共起を押し上げることがある。司会者を除いた集計や、質問ごとの確認を行う。

## 典型的な失敗と修正

| 失敗 | 修正 |
| --- | --- |
| 問いを決めずに頻出語の表から意味を探す | qta-p1に戻り、問いと比較の枠組みを設定する |
| 特徴語の差を「有意に多い」と書く | 出現率の差として記述し、検定が必要なら別に設計する |
| 共起ネットワークの線を因果や合意と読む | 代表的な発話をKWICで読み、関係の意味を原文で確認する |

## 結果のまとめ方

問い・比較の枠組み・注目概念 → 解析の条件としきい値 → 表 → 原文の確認と解釈 → 限界。
