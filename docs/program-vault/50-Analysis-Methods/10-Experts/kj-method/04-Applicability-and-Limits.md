# KJ法の専門家：適用条件と限界

## 入力データの条件

| 条件 | 満たさない場合 | 根拠 |
| --- | --- | --- |
| 研究目的がある | 要確認（`kj-a1`） | [文献] 関係線は研究目的に合わせて最小限（田中） |
| 分析できる発話がある | 分析を始めない（`kj-a2`） | [実装判断] |
| 発話が400件以下 | 要確認（`kj-a3`） | [実装判断] |
| ラベルの単位 | 研究者が確認（`kj-a4`） | [文献] 1ラベル1メッセージ（田中） |

## この手法の結果から言えないこと

- 島（グループ）の大きさやラベル数から、意見の重要性や支持人数（[整理]）。
- 自動クラスタリングやAIの分類をKJ法の結果とすること（[整理]、手順のラベル集めは研究者の判断）。

## グループインタビューでの注意

- [整理] 同じ意見が複数の参加者から出た場合、ラベルは発話ごとに作り、応答による同調か独立した意見かは相互作用分析と照合する。
- [実装判断] 話者の確認が済んでいない場合、ラベルに話者を書いても、その話者の意見と断定しない。
- [整理] 衆目評価に参加者自身が加わるか、研究者だけで行うかで意味が変わる。行った手続きを記録する。
