# KJ法の専門家：判断基準と品質確認

## 判断基準

- [文献] 事前にカテゴリーを想定しないボトムアップなグループ化（田中）。
- [文献] ラベルと表札は、中身を正確に表現できるよう文章で書く（川喜田ほか 2003、p.21、田中）。
- [文献] 文章化では、論理的な矛盾とデータからの解釈の逸脱に注意を払う（田中）。
- [文献] 図解化と言語化による提示と、衆目評価による合意形成（川喜田ほか 2003、p.6）。

## アプリが判定する項目と人が確認する項目

KJ法の品質は研究者の手作業の過程によるため、コードで判定する品質項目は置かない（[実装判断]）。`kj-q1`〜`kj-q5` はすべて研究者が確認する項目で、アプリは確認済みと表示しない。適用条件では、発話数の目安（400件）だけをコードで判定する。

## AIを使わない理由

[整理] ラベル集めは、内容の近さを研究者が判断してボトムアップに行う作業で、事前のカテゴリーや自動的な類似度で置き換えると手法の中心が失われる（田中の手順）。そのため、この専門家は `ai_assist.allowed: false` とし、KJ法を主手法に選んだ場合はAI見解を生成しない（[実装判断]）。

## ほかの手法との違い

[文献] グラウンデッド理論が概念的カテゴリーを礎石に理論を構成するのに対し、KJ法はばらばらにしたカードの意味的なエッセンスから組み立てる点で異なるとする解説がある（川喜田ほか 2003、p.26、聞き手による解説）。
