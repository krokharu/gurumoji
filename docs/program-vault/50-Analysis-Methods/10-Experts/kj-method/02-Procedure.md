# KJ法の専門家：手順

段階は [[50-Analysis-Methods/20-Literature/LIT-tanaka-kj-quick-manual|田中のKJ法クイックマニュアル]]（図2、p.103–105）による。

## 手順と各段階の確認事項

| 段階 | 内容 | 担当 | 確認事項 |
| --- | --- | --- | --- |
| kj-p0 | 下準備 | 研究者 | 音声データは文字起こしを行う（[文献] 田中） |
| kj-p1 | ラベルづくり | 研究者 | 1つのラベルには1つのメッセージが読み取れるデータを入れる。通し番号を付け、元データにも同じ番号を記載する（[文献] 田中）。ラベルは名詞だけで終わらせず文章で書く（[文献] 川喜田ほか 2003、p.21） |
| kj-p2 | ラベル拡げ | 研究者 | 並べる順番はランダム（[文献] 田中） |
| kj-p3 | ラベル集め | 研究者 | 内容からボトムアップにグループを作り、事前にカテゴリーを想定しない。小グループから作り、入らないラベルはそのままでよい（[文献] 田中） |
| kj-p4 | 表札づくり | 研究者 | 小グループの段階では表札を文章で作り、理論や専門用語に無理に当てはめない（[文献] 田中） |
| kj-p5 | 第2段・第3段 | 研究者 | 手順2〜4を繰り返し、解釈可能なグループ数になるまで行う。段ごとに番号と色を区別する（[文献] 田中） |
| kj-p6 | 空間配置 | 研究者 | 大グループから解釈しやすい順に並べる。グループ数が多すぎると図が複雑になり解釈が難しくなる（[文献] 田中） |
| kj-p7 | 図解化 | 研究者 | グループを囲み、関係線を大きいグループから結ぶ。関係線は研究目的に合わせて最小限（[文献] 田中） |
| kj-p8 | 文章化 | 研究者 | 論理的な矛盾、データからの解釈の逸脱に注意を払う（[文献] 田中） |
| kj-p9 | 提示と衆目評価 | 研究者 | 図解を読み込んで他者に説明する。衆目評価による合意形成（[文献] 川喜田ほか 2003、p.6、p.22） |

## 判断に迷いやすい点

- [実装判断] 1つの発話に複数のメッセージがある場合は、ラベルを分け、同じ発話IDに枝番を付けて対応させる。発話IDだけでは1ラベル1メッセージにならない。
- [文献] マニュアルは概略であり、実際に行う際は専門書を参照する必要があるとされる（田中、p.105）。
- [整理] 司会者の質問はラベルにしないか、別の色で区別する。参加者の意見と同じグループに混ぜない。

## 典型的な失敗と修正

| 失敗 | 修正 |
| --- | --- |
| 既存のカテゴリー名を先に決め、そこにラベルを振り分ける | ラベル拡げ（kj-p2）からやり直し、内容の近さだけで集める |
| 表札を名詞や専門用語だけで書く | グループのラベルの内容を要約した文章に書き直す |
| 関係線を多く引きすぎる | 研究目的に必要な関係だけを残す |
| 自動クラスタの結果をグループ編成として使う | KJ法の結果として示さず、研究者のラベル集めを行う |

## 結果のまとめ方

研究目的と使った版 → ラベルの一覧（通し番号と発話ID） → グループ編成の段階と表札 → 図解 → 文章化 → 限界。
