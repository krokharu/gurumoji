# Kilgarriff（2001）：Comparing Corpora

## 研究目的

コーパスを記述し比較する方法がコーパス言語学に不足しているため、異なるコーパスをより客観的に比較する方法を検討する（要旨）。

## 対象データと研究条件

二つのコーパス比較の結果を示す（要旨）。コーパスの内容は確認していない。

## 分析手順の要約

- あるコーパスに特徴的な語はどれかという問いについて、使われてきた統計的方法を検討・批判し、Mann-Whitneyの順位検定の使用を提案する。
- コーパスの類似度の尺度を検討し、類似度の尺度を評価する方法を示す（要旨）。

## 主要な知見

検討した類似度の尺度の中では、χ²に基づくものが最もよいとする。検討した方法はすべて語とn-gramの頻度に基づき、その方針を擁護する（要旨）。

## 適用上の注意と限界

- 要旨だけを読んだため、特徴語の検定を批判する理由の詳細は確認していない。
- コーパスの比較の文献であり、同じ会話の中の話者どうしの比較を直接扱ったものではない。
