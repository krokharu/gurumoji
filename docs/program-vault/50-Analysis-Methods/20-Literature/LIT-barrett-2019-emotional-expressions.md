# Barrett et al.（2019）：表情から感情を推論することの課題

## 研究目的

人の感情状態は顔の動き（いわゆる表情）から容易に推論できる、という広く共有された想定（「一般的な見方」）を取り上げ、それを検証する科学的な証拠を検討する（要旨）。

## 対象データと研究条件

研究の証拠の概観。怒り、嫌悪、恐れ、喜び、悲しみ、驚きの6つのカテゴリーを中心に扱う（要旨）。

## 分析手順の要約

一般的な見方の例を概観し、それを検証する証拠を検討する（要旨）。

## 主要な知見

- 人は喜ぶと笑うことが偶然より多いなど、一般的な見方に沿う証拠は一部ある。
- しかし、感情をどう伝えるかは文化、状況、同じ状況の中の個人でも大きく異なる。似た顔の動きの配置が複数の感情カテゴリーを表し、しかめ面のような配置が感情以外のことを伝えることも多い（要旨）。

## 適用上の注意と限界

- 対象は顔の動きであり、音声からの感情推定を直接扱ったものではない。
- 訂正記事がある：Corrigendum, Psychological Science in the Public Interest, 20(3), 165–166（2019-11-15、DOI: 10.1177/1529100619889954）。訂正の内容は読んでいない。
