# 田中：KJ法クイックマニュアル

## 研究目的

KJ法の手順を簡便にまとめた「KJ法クイックマニュアル（2013年版）」を提示する（概要、p.102）。

## 対象データと研究条件

手順の手引きであり、特定のデータの分析ではない。英語教育学研究での質的研究の発展を目的に挙げる。

## 分析手順の要約

KJ法には複数の流派やバージョンがあり、本マニュアルは川喜田（1997）の1997年版に基づく（p.102）。大きくは、データをラベル化するラベル作り、ラベルをまとめるグループ編成、グループを解釈可能な形に並べる図解化、図解化を解釈した叙述化の4つのステップからなる（p.102、図1）。図2の手順は次のとおり（p.103–105）。

| 段階 | 作業と注意 |
| --- | --- |
| 0. 下準備 | 音声データは文字起こしを行う。模造紙、ラベルなどの道具を準備する |
| 1. ラベルづくり | 1つのラベルには1つのメッセージが読み取れるデータを入れる。ラベルに通し番号を付け、元データにも同じ番号を記載する |
| 2. ラベル拡げ | ラベルをランダムな順番で机や床に並べる |
| 3. ラベル集め | 内容の似たラベルを集めて小グループにする。内容からボトムアップで作り、事前にカテゴリーを想定しない。どのグループにも入らないラベルはそのままでよい |
| 4. 表札づくり | 小グループの段階では表札を文章で作る。理論や専門用語に無理に当てはめた表札は避ける。表札にも通し番号を付ける |
| 5. 第2段のグループ編成 | 2〜4と同じ手順で、より大きなグループにまとめる。番号と色を第1段と区別する |
| 6. 第3段のグループ編成 | 解釈可能なグループ数になるまでグループ編成を繰り返す |
| 7. 大グループの空間配置 | 解釈しやすい順に並べる。グループ数が多すぎると図が複雑になり解釈が難しくなる |
| 8. 中グループの空間配置 | 7と同じ手順で、より小さいグループの配置を順に行う |
| 9. 図解化 | ラベルと表札を仮留めし、グループごとに囲み、関係線で結ぶ。関係線は大きいグループから結び、研究目的に合わせて最小限にする |
| 10. 文章化 | 論理的な矛盾と、データからの解釈の逸脱に注意を払う。妥当に解釈できれば文章化し、図解を清書する |

## 主要な知見

手順の手引きであり、実証的な知見の報告ではない。

## 適用上の注意と限界

- このマニュアルは概略であり、実際にKJ法を行う際は専門書を参照する必要があるとする（p.105）。
- 概要ではステップ名を「叙述化」、図2では「文章化」と表記している。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/kj-method/01-Expert|KJ法の専門家]]：図2の段階を手順の段階IDとして定義し、採用した版（1997年版に基づく田中のマニュアル）を流派として記録する。
- 禁止事項：事前にカテゴリーを想定したグループ化、類似度による自動分類をラベル集めとして扱うこと。どのグループにも入らないラベルを無理に分類すること。
- 品質確認：1ラベル1メッセージ、ラベルと元データの番号対応、表札が文章で書かれているか、関係線が最小限か、論理的矛盾とデータからの逸脱がないか。
- [実装判断] Gurumojiでは発話IDをラベルの通し番号に対応させる。ラベル集め以降の作業は研究者が行う。
