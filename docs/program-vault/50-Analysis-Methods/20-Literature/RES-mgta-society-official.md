# M-GTA研究会：M-GTAとは

## 研究目的

M-GTAがどのような意味でGTAの「修正版」なのかを説明する（ページの記述）。

## 対象データと研究条件

情報提供ページであり、特定のデータの分析ではない。

## 分析手順の要約

- M-GTAは切片化という技法を用いない。切片化は、ストラウス・コービン版、グレーザー版、シャーマズの試みを含む他のGTAに共有される技法だとする。
- データに着目する選択判断を導く視点として、分析テーマと分析焦点者を用い、分析ワークシートによる概念生成を進める。
- 分析テーマに「〜のプロセス」という言葉を入れるのは、最終的に動態的なプロセスを捉えようとするためで、ワークシートで概念を生成するときは、その概念が明らかになるプロセスのどこにどう関係しそうかを意識する。分析結果がすぐに出てきそうな場合は、分析テーマがまだ練られていないと考えて再検討する。
- 分析テーマと分析焦点者の調整から、二つ目の論文につながる別の分析テーマが設定できる場合もあるとする。

## 主要な知見

M-GTAは、限定された範囲で一般化しうる知識の生成を目的とし、その限定的な一般化は、研究する人間が分析焦点者を介して実践するという条件設定と、応用者が分析焦点者の視点を介して現実場面で活用するという条件設定の組み合わせで成立する、と説明する。ヒューマンサービス領域の実践を強調する。

## 適用上の注意と限界

研究会の情報提供ページであり、査読を経た資料ではない。記載は更新されうる。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/m-gta/01-Expert|M-GTAの専門家]]：分析テーマ（プロセスを捉える形）と分析焦点者の設定を適用条件にする。切片化を行う手順を混ぜない。
- 品質確認：分析テーマが練られているか（結果がすぐ出そうな設定になっていないか）を人の確認項目にする。
