# Poliandri et al.（2023）：オンライン・フォーカスグループの実施と参加

## 研究目的

イタリアの教員と校長を対象にしたオンライン・フォーカスグループの実施方法、運営上の課題、評価方法を報告する方法論記事。

## 対象データと研究条件

イタリアの42校から教員101名と校長37名が参加した13件の同期オンライン討議（2020年3月〜5月）。うち4件が校長、9件が教員のグループだった。各討議の平均時間は105分、合計録画時間は1,339分と報告される。参加バランスに関する表では、討議時間、参加者数、発話数、参加者あたりの平均発話数、発話数の標準偏差、60分換算の発話数を並べる。

## 分析手順の要約

音声・映像から自動作成した逐語録を人手で確認し、発話（fragment）単位の表に整理した。参加量の記述指標として、平均発話数／参加者と参加者あたり60分の発話数を算出し、語数などのテキスト量指標も報告した。

## 主要な知見

- 13件のオンライン討議で、1参加者あたりの発話数は平均8.58回だった。
- Table 2はグループ別の平均発話数と標準偏差を併記する。北部エミリア＝ロマーニャの教員グループでは、参加者あたり平均5.57回、標準偏差3.59だった。
- 著者らは、参加量を数える指標に加え、研究者の観察記録、ワードクラウド、逐語録の計量テキスト分析、参加者への結果提示を組み合わせて妥当性を検討した。
- 参加者数や会議時間が異なるため、総発話数だけでなく60分換算値も併記している。
- 異なる日程と参加者で行った13件の討議には管理プロトコルを用い、各回で同じスクリプトとアウトラインに沿って議論を進めた。これは本研究固有の設計事例であり、一般的な比較基準ではない。
- 参加者は、この研究における司会者の「真の傾聴」と「効果的な要約」の役割を認識したと報告された。

## 適用上の注意と限界

これは特定の研修事業に参加したイタリアの教員・校長による、オンライン同期討議の一事例である。平均発話数や60分換算値は記述指標であり、参加の公平さを判定する普遍的なしきい値ではない。発言の長さ、内容、相づち、重なり、司会者の発話を区別する必要がある。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/participation-balance/01-Expert|参加バランスの専門家]]：平均発話数と標準偏差、時間当たりの発話数を参加状況の記述指標として参照する。単一研究の値を普遍的なしきい値にしない。
- [[50-Analysis-Methods/10-Experts/focus-group-interaction/01-Expert|フォーカスグループ相互作用の専門家]]：自動逐語録の人手確認、量的指標・質的所見の併用、参加者が報告した司会者の傾聴・要約の評価を参照する。最後の評価はこの事例の報告として扱う。
- [[50-Analysis-Methods/10-Experts/cross-session-comparison/01-Expert|会話間比較の専門家]]：13件の同期オンライン討議を実施し、共通の管理プロトコル、スクリプト、アウトラインを使った一事例として参照する。必要な会話数や一般的な比較手続きの根拠にはしない。
