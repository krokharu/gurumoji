# Onwuegbuzie et al.（2009）：フォーカスグループのデータ収集と分析の枠組み

## 研究目的

社会科学研究でフォーカスグループのデータを分析する具体的な情報が少ないため、データ収集と分析のための質的な枠組みを提示する（要旨）。

## 対象データと研究条件

方法の枠組みの提案であり、要旨には特定のデータセットの記載はない。

## 分析手順の要約

1. フォーカスグループで収集できるデータの種類を特定する。
2. それらのデータの分析に適した質的データ分析の技法を特定する。
3. マイクロ・インターロキュター分析を導入する。どの参加者がどの質問に応答したか、応答の順序、応答の特徴、使われた非言語的コミュニケーションなどの細かな情報を収集・分析・解釈する。

また、会話分析がフォーカスグループのデータ分析に大きな可能性を持つとする。

## 主要な知見

言語的なコミュニケーションだけを分析する方法を超え、分析の厳密さを高める枠組みだと著者らは位置づける（要旨）。

## 適用上の注意と限界

要旨だけを読んだため、各分析技法の対応表、マイクロ・インターロキュター分析の記録様式は確認していない。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/focus-group-interaction/01-Expert|フォーカスグループの相互作用分析の専門家]]：誰が、どの質問に、どの順で応答したかを分析の観点に含める。
- [[50-Analysis-Methods/10-Experts/participation-balance/01-Expert|参加バランスの専門家]]：発話量の集計を、質問ごと・応答順の観察へ戻して読む根拠にする。
- [実装判断] Gurumojiの逐語録には非言語的コミュニケーションの記録がない。非言語の情報を使う分析は「データ不足」として扱う。
