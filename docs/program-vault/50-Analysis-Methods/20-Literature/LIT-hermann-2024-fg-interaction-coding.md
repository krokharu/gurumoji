# Hermann et al.（2024）：フォーカスグループの相互作用を分析するコーディング枠組み

## 研究目的

フォーカスグループの相互作用をデータ分析に体系的に含める方法を、コーディング枠組みを使って示す。目的は三つで、相互作用のコーディング枠組みを作ること、相互作用の分析をテーマ分析の過程に組み込む手順を試して記述すること、枠組みを別のデータで試すことである（要旨）。

## 対象データと研究条件

青年を対象とした5回のフォーカスグループ面接。別の場面の青年のフォーカスグループ1回で枠組みを試した（要旨）。

## 分析手順の要約

1. フォーカスグループの文献に基づき、相互作用を表す記号を含むコーディング枠組みを作る。
2. 5回分のデータをこの枠組みでコード化する。
3. 特定した相互作用の分析を、テーマ分析（例示としてSystematic Text Condensationを使用）と同時に進める。
4. 別のデータで枠組みを試し、二人のコーダーの結果を比べて枠組みをわずかに修正する。

## 主要な知見

作成した枠組みは、テーマ分析の過程を通じて相互作用を見える形にし、考慮に入れることを助ける実用的な道具だとする（要旨）。

## 適用上の注意と限界

要旨だけを読んだため、枠組みの項目と記号、コーダー間の比較方法は確認していない。対象は青年のフォーカスグループであり、他の対象への適用は確認していない。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/focus-group-interaction/01-Expert|フォーカスグループの相互作用分析の専門家]]：相互作用のコード化を、テーマ分析など内容の分析と並行して行う流派があることを記録する。
- [[50-Analysis-Methods/10-Experts/thematic-analysis/01-Expert|テーマ分析の専門家]]：グループデータでは、相互作用をテーマの検討に含める選択肢があることを示す。
- [実装判断] Gurumojiの相互作用タグは研究者が定義するもので、本文献の枠組みを実装したものではない。
