# Hermann et al.（2024）：フォーカスグループの相互作用を分析するコーディング枠組み

## 研究目的

フォーカスグループの相互作用をコード化し、相互作用分析をテーマ分析（Systematic Text Condensation）と並行して行う方法を示す。別のデータにも枠組みを適用し、使いやすさを検討している。

## 対象データと研究条件

15～18歳の青年27人による対面フォーカスグループ5回で枠組みを作成し、別のフォーカスグループデータでも試行した。これは一つの研究での開発・試行であり、異なる対象や研究環境における妥当性を確立した検証ではない。

## 分析手順の要約

1. 参加者間の応答を示す記号付きの相互作用コードを作る。
2. 発話をSystematic Text Condensationの意味単位に整理し、意味単位に相互作用の記号を対応づける。
3. 別データでも枠組みを試し、試行で扱いにくかった項目や重複する項目を見直す。

## 主要な知見

最終的な枠組みは、同意、不同意、差異化、考え・意見の変化、異なる語の使い方、反復、参加者の関与、沈黙化の8種類を扱う。これらは参加者間の応答や相互作用を記録するコードであり、発話交替を時系列に測る指標やフォーカスグループ全体の品質評価尺度ではない。

## 適用上の注意と限界

- 相互作用を捉えるには、休止、笑い、参加者どうしの割り込みなどを記した高品質な逐語録が必要とされる。声の高まりや感情表現を捉えにくい場合は、音声、映像、司会・観察者の記録が補助になる。
- 意見表明が少なく相互作用が低いデータでは、枠組みを使う利点が小さく、負担に感じられる可能性がある。すべてのデータで全コードが現れるわけではない。
- 枠組みは青年のフォーカスグループを中心とした一つの研究で開発・試行された。別の対象への適用時には、コード定義とデータの適合を研究者が確認する。
