# 木下（2007）：M-GTAの分析技法

## 研究目的

修正版グラウンデッド・セオリー・アプローチ（M-GTA）の考え方と分析技法を、研究を進める流れに沿って説明する（講演に基づく論文）。

## 対象データと研究条件

方法の解説であり、特定のデータセットの分析結果は報告していない。

## 分析手順の要約

- M-GTAの構成を、実際に作業として行う「作業項目」（研究テーマ、分析テーマ、分析焦点者、分析ワークシートによる概念生成、カテゴリー生成、理論的メモノート、結果図とストーリーライン、グラウンデッド・セオリー）と、分析の考え方を示す「機能項目」（継続的比較分析、理論的サンプリング、理論的メモ、理論的センシティビティ、理論的飽和化）に分ける（p.1）。
- 研究テーマを設定した後、分析テーマを設定する（5節、p.4–5）。
- 分析焦点者を決める。修正版ではデータの切片化をせず、切片化せずに解釈を進めるために分析焦点者を設定する（6節、p.5）。
- 面接記録であれば最初に1人分の全体に目を通し、データのある部分に着目してその意味を幾通りか検討し、定義として採用するものを決めて概念表現を考える。採用しなかった解釈案は理論的メモとして必ず記入する（p.6）。
- 生成した概念は分析ワークシートに記入する。1概念につき1ワークシートで、項目は概念名、定義、具体例であるヴァリエーション、理論的メモ。解釈した意味は短文の定義にし、定義にならなかった他の解釈案は理論的メモ欄に入れる。反対例や類似例も記入し、複数の概念のワークシートを同時並行で進める（8節、p.7）。
- 新たに重要な概念が生成されなくなり、理論的サンプリングで新たに確認すべき問題点がなくなったときに飽和化したと判断する。分析結果が成立するデータの範囲の調整も含めて判断する立場をとる（p.8）。
- 論文執筆の前に、分析結果を生成した概念とカテゴリーだけで簡潔に文章化したストーリーラインを書く。結果は結果図でも示す（p.9）。

## 主要な知見

- 現在のグラウンデッド・セオリー・アプローチは4つのタイプに分化しており、最も重要なのは1960年代にグレーザーとストラウスが示したオリジナル版だとする。修正版はそのタイプの一つ（2節、p.2–3）。
- 修正版の基本特性として、データに基づく分析であること、論理実証主義ではなく経験的という意味での実証性（グレーザーから学ぶもの）、深い解釈とその意味を凝縮して名付けることの重要性（ストラウスから学ぶもの）を挙げる（p.3）。
- コーディングの基本は、データを解釈してコードに置き換えることと、コードから元のデータへたどれるようにしておくことの2点で、どのタイプのGTAや他の質的研究法でも共通だとする（p.4）。
- 生成した概念と概念の関係から分析結果をまとめるため、類型ごとの人数や頻度のような度数的な結果表示は成り立たないとする（p.4）。

## 適用上の注意と限界

- 適した研究として、ヒューマンサービス領域、現象そのものがプロセス的な性格を持つ場合を挙げる（3節、p.3）。
- 最後の節で、方法論に対してよく提起される批判と疑問に触れている（10節、p.9–10）。
- 講演に基づく解説であり、M-GTAの詳しい手順は著者の書籍にあると考えられるが、書籍は読んでいない。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/m-gta/01-Expert|M-GTAの専門家]]：分析テーマと分析焦点者を必須の入力にする。未設定なら分析を始めない。
- 手順：分析ワークシート（1概念1ワークシート、概念名、定義、ヴァリエーション、理論的メモ、反対例）、カテゴリー生成、結果図、ストーリーラインを段階IDとして定義する。
- 禁止事項：人数や頻度を結果として示さない。切片化を前提とする他のGTAの手順と混ぜない。
- 適用条件：プロセス的な性格を持つ現象か、研究者が確認する項目にする（コードで判定しない）。
