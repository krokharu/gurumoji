# Sacks, Schegloff & Jefferson（1974）：会話のターン交替の組織

## 研究目的

会話と他の発話交換システムにとって基本である、話す順番（ターン）の交替の組織について、会話のためのモデルを提案する（要旨）。

## 対象データと研究条件

要旨には対象データの記載はない。

## 分析手順の要約

提案したモデルを、会話について大まかに観察できる事実の一覧と整合するかで検討する（要旨）。

## 主要な知見

会話のターン交替のモデルは、局所的に管理され、当事者によって運営され、相互作用的に制御され、受け手に合わせた設計に敏感なものとして特徴づけられるとする。モデルの一般的な帰結を説明し、他の発話交換システムのターン交替の組織と対比する（要旨）。

## 適用上の注意と限界

要旨だけを読んだため、モデルの規則の詳細は確認していない。
