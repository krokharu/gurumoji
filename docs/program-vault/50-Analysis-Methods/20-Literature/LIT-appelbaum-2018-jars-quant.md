# Appelbaum et al.（2018）：心理学の量的研究の論文報告基準（JARS-Quant）

## 研究目的

既存の報告基準の見直しと、最初の基準（2008年）以降10年の経験を踏まえ、量的研究の報告基準の修正を提案する（要旨）。

## 対象データと研究条件

報告基準の検討であり、特定のデータの分析ではない。

## 分析手順の要約

要旨の範囲で、主な修正点：

- 仮説、分析、結論を、主要（primary）、副次（secondary）、探索的（exploratory）の3つに分けて扱う。
- 観察研究、臨床試験、縦断研究、再現研究、N-of-1研究の報告基準の単元を加え、構造方程式モデリングとベイズ分析の基準を含める。

## 主要な知見

提案はAPAの委員会に承認され、APA出版マニュアル第6版（2010）の基準に置き換わるとする（要旨）。

## 適用上の注意と限界

- 要旨だけを読んだため、各基準の項目は確認していない。
- 訂正記事がある：American Psychologist, 73(7), 947（2018年10月、DOI: 10.1037/amp0000389）。訂正の内容は読んでいない。
