# 川喜田ほか（2003）：KJ法の原点と核心を語る

## 研究目的

KJ法の創始者である川喜田二郎へのインタビューを、現場の語り口を生かしてまとめ、KJ法の発想の原点と方法論の特徴を示す（要約、p.6）。

## 対象データと研究条件

インタビュー記事。聞き手は松沢哲郎とやまだようこ。

## 分析手順の要約

要約（p.6）は、方法論の基本的な特徴として次の6点を挙げる。

1. 現場取材と創造的総合の二つからなるフィールド科学
2. ありのままのデータからボトムアップで認識する方法論
3. フィールドノートではなくカードに記述することによる、自由で多様な組み合わせの可能性
4. 意味を重視した文章の見出しを多段階で使うこと
5. 雑多なデータを図解化によって統合すること
6. 図解化と言語化による提示と、衆目評価による合意形成

本文での具体的な発言：

- ラベルは原則として名詞だけで終わらせず、「何々は何々である」のように文章で書く。名詞だけでは中身を正確に表現できないため、原則として動詞を使って書くとする（p.21）。
- 作成した図解を読み込んで他者に説明すること、衆目評価に触れる（p.22）。

## 主要な知見

- KJ法の発想の原点には、今西学派の特徴である未知への冒険精神と、生きた世界に実践的に関与しながら認識するという根本姿勢があったとまとめる（要約、p.6）。
- 聞き手のやまだようこによる解説は、グラウンデッド理論が概念的カテゴリーを礎石にして概念的に理論を構成するのに対し、KJ法は一度ばらばらにしたカードの意味的なエッセンスから組み立てる点で根本的に異なると論じる（p.26）。

## 適用上の注意と限界

- インタビュー記事であり、手順を体系的に記述したものではない。手順の根拠には [[50-Analysis-Methods/20-Literature/LIT-tanaka-kj-quick-manual|田中のKJ法クイックマニュアル]] を併用する。
- p.26の比較は、川喜田本人ではなく聞き手による解説の記述である。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/kj-method/01-Expert|KJ法の専門家]]：ラベルは一つの意味を持つ文章で書く、ボトムアップで統合する、図解化と文章化の両方で示す、を手順と品質確認に含める。
- 衆目評価（他者への説明と評価による合意形成）を、研究者が行う確認として記録する。Gurumojiでは実施を代行しない（[実装判断]）。
- グラウンデッド理論やコーディングによるカテゴリー化と混同しないよう、流派の違いとして記録する。
