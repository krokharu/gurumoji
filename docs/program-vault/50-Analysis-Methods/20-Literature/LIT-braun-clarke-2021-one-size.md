# Braun & Clarke（2021）：（再帰的）テーマ分析の質とは何か

## 研究目的

テーマ分析（TA）の普遍的な品質基準を作ることの難しさを論じ、特に再帰的TAについて質の高い実践を検討する（要旨）。

## 対象データと研究条件

著者らの手引きを引用する、または従うと述べる公刊されたTA研究に見られる問題を検討している（要旨）。対象論文の選び方は確認していない。

## 分析手順の要約

公刊されたTA研究に見られる10の共通の問題を手がかりに、TAの質を論じる（要旨）。

## 主要な知見

- TAには、パラダイム、哲学、手続きの異なる多くの形があり、普遍的な品質基準を作ることを難しくしている。
- この多様性は編集者、査読者、著者に認識されておらず、「コーディングの信頼性の測定」がTAの質の普遍的な条件として求められることがある。
- 共通の問題の多くは、TAが一つの均質な方法だという想定に基づく。
- 査読者と編集者向けに、20の重要な問いの形で指針を示す（要旨）。

## 適用上の注意と限界

要旨だけを読んだため、10の問題と20の問いの内容は確認していない。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/thematic-analysis/01-Expert|テーマ分析の専門家]]：どの形のTAを使うのかを必ず記録させ、コーディングの信頼性の測定を全ての形のTAに共通する品質条件として扱わない。
- 流派が記録されていない場合は、品質確認の基準を決められないと表示する。

## 根拠の位置情報

要旨。

## 未確認事項

本文の10の問題と20の問い。
