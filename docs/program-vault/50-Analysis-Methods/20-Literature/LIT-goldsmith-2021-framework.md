# Goldsmith（2021）：Using Framework Analysis in Applied Qualitative Research

## 研究目的

フレームワーク分析の手順を、特集号の共通データを二次分析する実例で示し、応用研究での価値を論じる（要旨）。

## 対象データと研究条件

特集号の共通データセットを二次分析している（要旨）。データの内容は確認していない。

## 分析手順の要約

- フレームワーク分析は、帰納的・演繹的に導いたテーマの構造（フレームワーク）を使って、記述と抽象化を組み合わせた横断的な分析を行う、比較を本質とするテーマ分析の一形態とする。
- 主な構成要素は、分析のフレームワークを作ることと、それを適用することの二つ。
- 5段階：データへの精通、フレームワークの特定、インデックス付け、チャート化、マッピングと解釈。

## 主要な知見

フレームワーク分析は応用政策研究の質的データを分析する目的で開発されたため、応用研究によく合うとする。事例の中・事例間、テーマの中のパターンを特定・記述・解釈することを全体の目的とし、分析単位を複数の観点から検討する重要性を示す（要旨）。

## 適用上の注意と限界

要旨だけを読んだため、各段階の作業内容、分析単位の検討の具体例は確認していない。[[50-Analysis-Methods/20-Literature/LIT-gale-2013-framework|Gale et al. 2013]] の7段階とは段階の区切り方が異なる。
