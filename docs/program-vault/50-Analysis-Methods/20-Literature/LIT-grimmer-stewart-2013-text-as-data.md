# Grimmer & Stewart（2013）：Text as Data

## 研究目的

政治学の研究者向けに、自動テキスト分析という研究領域の手引きを示す（要旨）。

## 対象データと研究条件

政治的なテキストを対象とする方法の概観（要旨）。

## 分析手順の要約

幅広い新しい方法を概観し、モデルの出力をどう検証するかの指針を示し、文献に見られる誤解や誤りを明らかにする（要旨）。

## 主要な知見

- 自動テキスト分析は、大量のテキストを分析する費用を大きく下げる。
- 一方で、自動的な方法は注意深い思考と精読の代わりにはならず、問題ごとの広範な検証を必要とする。
- 自動テキスト分析が標準的な道具になるには、新しい方法と新しい検証方法の開発が必要だと論じる（要旨）。

## 適用上の注意と限界

要旨だけを読んだため、検証の具体的な指針は確認していない。政治学のテキストを対象にしており、会話の逐語録を直接扱ったものではない。
