# Kidd & Parshall（2000）：フォーカスグループ研究の分析の厳密さ

## 研究目的

フォーカスグループのデータの解釈に内在する分析上の課題を記述し、分析を改善する方法を提案する（要旨）。

## 対象データと研究条件

要旨には特定のデータセットの記載はない。

## 分析手順の要約

取得できた要旨の範囲では、具体的な手順の記載はない。

## 主要な知見

フォーカスグループの文献では、グループの組織と実施に比べて分析の問題への関心が少ない。集団の力学の活用が利点とされる一方、集団の談話と個人の談話の違いが分析と解釈にどう影響するかについて、文献の指針はほとんどないとする（要旨）。

## 適用上の注意と限界

要旨だけを読み、しかも末尾が欠けているため、提案された方法は確認していない。
