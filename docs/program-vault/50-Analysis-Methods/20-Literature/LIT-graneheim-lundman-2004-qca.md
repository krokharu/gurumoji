# Graneheim & Lundman（2004）：看護研究における質的内容分析の概念・手順・信用性

## 研究目的

質的内容分析について、概念の意味と使い方、手順、解釈に関して文献の見解が分かれている状況を踏まえ、重要な概念を整理し、研究手順の中での使い方と信用性を高める方法を示す（要旨）。

## 対象データと研究条件

方法の解説であり、要旨には特定のデータセットの記載はない。

## 分析手順の要約

要旨で整理される概念：顕在的内容（manifest content）と潜在的内容（latent content）、分析単位、意味単位（meaning unit）、凝縮（condensation）、抽象化（abstraction）、内容領域、コード、カテゴリー、テーマ。

## 主要な知見

研究手順の各段階で、信用性（credibility、dependability、transferability）を高める方法を提案する。質的内容分析の解釈を、Watzlawickらのコミュニケーション理論に照らして論じる（要旨）。

## 適用上の注意と限界

要旨だけを読んだため、各概念の定義、凝縮・抽象化の具体例は確認していない。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/qualitative-content-analysis/01-Expert|質的内容分析の専門家]]：分析単位と意味単位を分析設定で明示させる。顕在的内容を扱うのか潜在的内容を扱うのかを、結果の説明で区別する。
- [実装判断] Gurumojiの分析単位は発話（`analysis_unit: turn`）で固定されている。意味単位が発話と一致しない場合は、研究者が注釈で扱う必要があると表示する。

## 根拠の位置情報

要旨。
