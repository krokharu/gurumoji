# KH Coderの公式サイト

## 研究目的

KH Coderを、計量テキスト分析またはテキストマイニングのためのソフトウェアとして紹介する（トップページ）。

## 対象データと研究条件

アンケートの自由記述、インタビュー記録、新聞記事など、さまざまなテキストの分析に使えるとする。

## 分析手順の要約

トップページでは、統計解析と元テキストの文脈とを行き来できること、分析にネット接続が不要なことを特徴に挙げる。

## 主要な知見

公式サイトの紹介であり、研究上の知見ではない。
