# Gale et al.（2013）：多職種の保健医療研究におけるフレームワーク法

## 研究目的

臨床家、患者、一般の人を含む多職種の研究チームでフレームワーク法を使う手順を、公刊された研究の例を使って説明する（Abstract、Background）。

## 対象データと研究条件

方法の解説であり、段階の例示に著者らの公刊研究の例を使う。

## 分析手順の要約

フレームワーク法は、1980年代後半に英国の研究機関のRitchieとSpencerが大規模な政策研究のために開発したと説明する（Background）。7段階（Procedure for analysis）：

| 段階 | 内容 |
| --- | --- |
| 1. Transcription | 質の良い録音と、可能なら逐語の書き起こし |
| 2. Familiarisation with the interview | 録音や書き起こしに慣れ親しむ。分析者と面接者が異なる場合に特に重要。余白に分析的なメモを残せる |
| 3. Coding | 書き起こしを1行ずつ読み、重要と解釈した箇所に言い換えやラベル（コード）を付ける。帰納的な研究では、関係しうるものを多くの観点からコード化する（open coding） |
| 4. Developing a working analytical framework | 最初の数件をコード化した後、関係する研究者が集まってラベルを比べ、以後の書き起こしに使うコードの組に合意する。コードをカテゴリーにまとめ、明確に定義して作業用の枠組みにする。数回の改訂が必要になりうる |
| 5. Applying the analytical framework | 以後の書き起こしに枠組みを適用してインデックスを付ける。質的データ分析ソフトはデータを保存・整理する道具で、データを分析するわけではない |
| 6. Charting data into the framework matrix | 表計算で行列を作り、書き起こしごとにカテゴリー別にデータを要約して記入する。面接1時間で15〜30頁の文章が生じうる。慣れれば1時間分の書き起こしにつき平均で約半日かかる |
| 7. Interpreting the data | 印象や考えを記録し、分析メモを書いてチームで議論しながら、特徴や違いを解釈する |

## 主要な知見

- 経験のある質的研究者の指導の下で使えば、体系的で柔軟な方法であり、質的研究の経験がないメンバーを含むチームにも適するとする（Summary）。
- 帰納的・演繹的のどちらにも与しない方法で、どちらに位置するかは研究質問によるとする（Background）。
- 内省（reflexivity）、厳密さ、質はフレームワーク法でも必要だとする（Background）。

## 適用上の注意と限界

- すべての質的データや研究質問に適する道具ではなく、量的研究者向けの「簡単な」質的研究でもない。非常に異質なデータは扱えず、データが分類できる程度に似たトピックや主要な論点を含む必要がある（Background）。
- ケースとテーマで分析することが適切でない研究質問では避けるべきで、例えば生活史のデータは語りの分析、診療場面の録音は会話分析、文書データは談話分析のほうが適する場合があるとする（Background）。
- 表計算の見た目のため、「20人中13人がXと述べた」のような数値化の誘惑があるが、質的研究の標本は代表性ではなく現象の多様性を捉える目的で選ぶため、そのような記述は意味をなさないとする（Discussion）。
- 時間と資源を多く要する（Discussion）。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/framework-method/01-Expert|フレームワーク法の専門家]]：7段階を手順の段階IDにする。枠組みの作成（段階4）はコード化の後に研究者が合意して行い、AIが枠組みを確定しない。
- 適用条件：データが共通のトピックを含むこと（半構造化面接など）。複数のケース（話者、グループ）と比較する枠組みがない場合は警告する。
- 禁止事項：行列のセルの件数から「何人中何人」と支持の程度を述べない。
- [[50-Analysis-Methods/10-Experts/cross-session-comparison/01-Expert|会話間比較の専門家]]：ケース×テーマの行列から元の発話へ戻る手順の根拠にする。
- [[50-Analysis-Methods/08-Common-Knowledge/03-Group-Interview-Data|共通知識]] の「観測は独立ではない」の節に反映した。
