# Elo & Kyngäs（2008）：The qualitative content analysis process

## 研究目的

帰納的な内容分析と演繹的な内容分析の過程を説明する（要旨）。看護研究で質的内容分析がよく使われる一方、分析過程の記述が少ないことを背景に挙げている。

## 対象データと研究条件

方法の解説であり、要旨には特定のデータセットの記載はない。

## 分析手順の要約

- 帰納的・演繹的のどちらも、準備（preparation）、組織化（organizing）、報告（reporting）の三つの段階で表す。準備の段階は両者で似ている。
- 帰納的な内容分析では、概念をデータから導く。演繹的な内容分析では、先行する知識に基づいて分析の構造を操作的に定める。
- 分析の目的は、現象を概念の形で記述するモデルを作ることとする。

## 主要な知見

帰納的な内容分析は、その現象を扱った先行研究がない場合や知識が断片的な場合に使う。演繹的なアプローチは、既存の理論を別の状況で検証する場合や、異なる時期のカテゴリーを比べる場合に役立つとする（要旨の結論）。

## 適用上の注意と限界

要旨だけを読んだため、各段階の具体的な作業、抽象化の手順、図は確認していない。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/qualitative-content-analysis/01-Expert|質的内容分析の専門家]]：帰納的か演繹的かの選択を、先行研究・既存理論の有無という研究条件で判断する。準備・組織化・報告を手順の大きな区切りとして使う。
