# 樋口（2017）：計量テキスト分析およびKH Coderの利用状況と展望

## 研究目的

KH Coderを利用した応用研究を概観し、どのように利用すればデータから社会学的に意義のある発見を導きやすいかを検討する（p.334）。

## 対象データと研究条件

インターネット上のコミュニケーション、マス・コミュニケーション、社会調査データ、会議録を分析した8つの応用研究を、著者の基準で選んで検討した（3.1節、p.336）。

## 分析手順の要約

- 計量テキスト分析で言葉を計量的に分析する理由として、データ探索（どの部分を人間が詳しく見るべきかの示唆）と、誰が操作しても同じ結果になる図表による分析の信頼性向上を挙げる（2.1節、p.335）。
- 人間が文章を読んで質的に解釈することを否定せず、計量的分析の結果を参考にもとの文章を質的に解釈し、質的解釈の発見に応じて計量的分析を修正する、循環的な関係として捉える（2.1節、p.335）。
- 内容分析の考え方を受け継ぎ、分析方法に信頼性・妥当性を求め、単なる記述でなく送り手・受け手の状況の推論を含むとする（2.2節、p.335–336）。
- コーディングルールは「発言にこの言葉が含まれていれば特定の概念とみなす」といった基準の集まりで、公開すると分析の信頼性を高めるだけでなく分析概念の汎用性を高めるとする（3.2.2節、p.339）。
- インタビュー記録の分析では、事前に計量テキスト分析で全体像をつかみ、複数グループ間の発言内容の違いを把握すると、質的分析の道しるべとして役立つことがあるとし、共起ネットワークの比較から質的な分析へ進んだ例を紹介する（3.4.2節、p.343–344）。

## 主要な知見

- 「分析すれば何か意味のある結果が出るだろう」という取り組み方は推奨できず、問い、比較の枠組み、注目する概念をなるべく具体的に設定してから分析を始めることが確実な方策だとする。帰納的な分析には、解釈のための十分な時間と当該分野への造詣が必要だとする（4節、p.346）。
- 取り上げた8研究はすべて何らかの比較を行っていた。比較の枠組みは、明確な区別のあるものを比べること、比較対象が適度に具体的な同一の概念に含まれること、先行研究や事前調査を十分に検討することが望ましいとする（4節、p.347）。
- 当該分野の詳細な知識があるから重要な語を見いだせた例を挙げる（3.5.2節、p.345–346）。

## 適用上の注意と限界

- 著者自身が開発したソフトウェアの利用状況の検討であり、応用研究の選択は著者の総合的な判断による（3.1節）。
- 比較の枠組みの検討が中心で、問いの立て方や注目概念の決め方の検討は今後の課題とする（4節、p.348）。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/quantitative-text-analysis/01-Expert|計量テキスト分析の専門家]]：研究質問、比較の枠組み、注目する概念の設定を適用条件にする（未設定なら「探索のみ」と表示）。計量結果から原文へ戻る確認（KWIC）を手順に含める。
- [[50-Analysis-Methods/10-Experts/cross-session-comparison/01-Expert|会話間比較の専門家]]：比較するグループが明確に区別でき、同一の概念に含まれるかを研究者が確認する項目にする。
- 禁止事項：語の頻度や共起の図だけから、領域の知識と原文の確認なしに結論を書かない。
