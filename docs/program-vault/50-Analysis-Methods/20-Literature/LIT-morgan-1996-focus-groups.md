# Morgan（1996）：Focus Groups

## 研究目的

社会学を含む多くの領域で再び広く使われるようになったフォーカスグループとグループインタビューを概観する（要旨）。

## 分析手順の要約

## 主要な知見

- フォーカスグループは単独の方法としても、質問紙調査や個人の詳細面接と組み合わせても使われる。
- 質問紙調査・個人面接との比較から、グループの利点と欠点が分かる。その中心は、相互作用を生み出すグループの役割と、それを導く司会者の役割である。
- 利点は、プロジェクトとグループの両方の水準で研究デザインに注意することで最大化できる。
- 今後の方向として、報告基準の整備、方法論の研究、データ分析の問題への注意、参加者の関心への関与を挙げる（要旨）。
