# Iseki（2023）：M-GTAを用いた転移性乳がん患者の心理的適応過程の分析

## 研究目的

転移性乳がん（MBC）と診断され薬物療法を受ける成人女性が、心理的適応に至る過程を明らかにする。

## 対象データと研究条件

MBCと診断された成人女性21人（平均年齢50歳）への半構造化面接を分析した。年齢は20～65歳で、研究者は対象数が少ないことを限界として述べている。分析結果はこの臨床領域と対象者に関するものである。

## M-GTAの説明と分析手順

著者は、分析焦点者を設定し、データを切片化せず解釈を通じて説明概念を生成し、概念間の関連を検討して限定された範囲の理論を導く方法としてM-GTAを説明する。また、人間同士の社会的相互作用に焦点を置き、対象現象がプロセス的な研究に適すると述べる。これは本研究が参照する方法の説明であり、M-GTA全体を網羅する方法論文献ではない。

本研究の分析テーマは、MBC診断後の薬物療法の選択と、治療を繰り返す中で心理的適応に至る過程である。著者はテーマに関するデータが豊富な参加者1人を最初に選び、着目点から概念を生成した。各概念について名称、定義、具体例、理論的メモを含むワークシートを作り、2人目以降の事例では類似点と相違点を比較した。概念間の関係からカテゴリーとサブカテゴリーを作成し、結果図とストーリーラインをまとめた。最終的に7カテゴリーと21概念を報告している。

## 分析の確からしさに関する記述

がん看護と質的研究に詳しい研究者から分析過程を通じて指導を受け、概念・カテゴリーを検討するためデータを繰り返し確認した。分析ワークシートと理論的メモを用いて、具体例の抽出から概念・カテゴリー生成、ストーリーライン作成までの分析経路を示した。

## 適用上の注意と限界

- 単一の臨床テーマと21人のMBC患者に対する適用例であり、ここで報告されたカテゴリーや心理的過程を他の集団に一般化しない。
- M-GTAの方法説明を補う応用研究として使う。方法の定義・手順の主な根拠には、木下の方法論文献と公式資料を引き続き用いる。
- 本文の限界として、対象者数が少ないこと、65歳を超えるMBC患者を含まないことが挙げられている。
