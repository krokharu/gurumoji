# Hsieh & Shannon（2005）：Three Approaches to Qualitative Content Analysis

## 研究目的

質的内容分析が単一の方法ではなく、三つのアプローチに分かれることを示し、それぞれの手順と信用性（trustworthiness）への対応を説明する（要旨）。

## 対象データと研究条件

要旨によれば、終末期ケアの領域から作った仮想の例で説明している。

## 分析手順の要約

要旨の範囲で、次の三つを区別する。

| アプローチ | コードの出所 |
| --- | --- |
| 慣習的（conventional） | コーディングのカテゴリーをテキストデータから直接導く |
| 有向的（directed） | 理論や関連研究の知見を初期コードの手がかりにして始める |
| 要約的（summative） | キーワードや内容を数えて比べ、その後に背景にある文脈を解釈する |

三つの違いは、コーディングの枠組み、コードの出所、信用性への脅威にあるとする。

## 主要な知見

三つのアプローチはいずれもテキストデータの内容から意味を解釈するもので、自然主義的パラダイムに沿うとする（要旨）。

## 適用上の注意と限界

要旨だけを読んだため、各アプローチの具体的な手順、信用性を高める技法の内容は確認していない。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/qualitative-content-analysis/01-Expert|質的内容分析の専門家]]：慣習的・有向的・要約的を流派の選択肢として保持し、コードの出所（データから／理論から／語の計数から）を分析設定に記録させる。
- 要約的アプローチでも、数えた後に文脈の解釈を行うことを手順に含める。数えた結果だけで分析を終えない。語の計数を中心とする分析は [[50-Analysis-Methods/10-Experts/quantitative-text-analysis/01-Expert|計量テキスト分析の専門家]] と役割を分ける。
