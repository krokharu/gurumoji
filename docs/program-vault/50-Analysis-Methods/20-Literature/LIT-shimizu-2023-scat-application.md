# Shimizu et al.（2023）：日本とタイの高齢者が大切にする生活要素の質的研究

## 研究目的と対象

日本とタイの高齢者が生活の喜びや充実感をどう捉えるかを調べた研究。半構造化面接の対象は14人（日本7人、タイ7人）。

## SCATの説明と本研究での適用

著者らはSCATを、データ中の語句を選ぶ、外部語句で言い換える、概念を取り出す、テーマ・構成概念を推論するという4段階の逐次的なコード化と、その後のストーリーライン・理論記述からなるテーマ分析法として説明する。

本研究の実際の分析は6段階で記述される。SCATフォームへの記入、個人内のデータ片の分類と類似データのグループ化、各グループの言い換え、グループ間の関係からテーマを概念化し、全データを含むストーリーラインと理論を書く手順である。著者らは参加者間の類似・相違を比べ、データ収集と分析を反復し、SCAT経験者の監督を受けたと報告する。

## 適用上の注意

- 4段階の一般的説明は、SCATの原典・方法論文献を置き換える根拠ではない。手法の定義と標準手順には大谷の文献を引き続き用いる。
- グループ化や6段階の流れはこの研究の適用手順として扱う。SCAT一般の必須手順として移さない。
- 対象は日本・タイの高齢者14人への面接であり、報告された生活観を他の集団へ一般化しない。
