# Braun & Clarke（2006）：Using thematic analysis in psychology

## 研究目的

テーマ分析（TA）は心理学で広く使われながら、境界があいまいで方法として明示されることが少ない。そこでTAの理論的な位置づけと方法を示し、理論的な裏付けがありつつ柔軟な手引きを提供する（PDF p.1）。

## 対象データと研究条件

方法の論文で、例示には研究文献と著者ら自身の研究を使う（PDF p.3）。

## 分析手順の要約

- 用語として、研究で集めたデータ全体（data corpus）と、特定の分析に使うデータ（data set）を区別する（PDF p.3）。
- 分析の前に次の判断を明示的に検討し、分析の過程を通じて研究者が内省的に吟味する（PDF p.6–9）。
  - 何をテーマとみなすか。テーマは研究質問に関してデータの重要な何かを捉え、データの中の一定のパターンを持つ応答や意味を表す（PDF p.6）
  - データ全体の豊かな記述を目指すか、特定の側面の詳しい説明を目指すか（PDF p.7）
  - 帰納的（ボトムアップ）なTAか、理論的・演繹的（トップダウン）なTAか（PDF p.7）
  - 意味的（semantic、明示的）な水準か、潜在的（latent、解釈的）な水準か。通常はどちらか一方に主に焦点を当てる（PDF p.8）
  - 認識論として本質主義・実在論か構築主義か。TAはどちらのパラダイムでも行えるが、結果と焦点が異なる（PDF p.9）
- 分析の6段階（Table 1、PDF p.11）：1. データに慣れ親しむ（必要なら書き起こし、繰り返し読み、最初の考えを書き留める）、2. 初期コードを作る、3. テーマを探す、4. テーマを見直す、5. テーマを定義し名付ける、6. 報告を作る。

## 主要な知見

- テーマがデータから「浮かび上がった」という記述が珍しくないことを問題として取り上げる（PDF p.4）。
- TAを行う際の落とし穴を挙げる（PDF p.18–19）。
  1. そもそもデータを分析していない（抜粋を並べるだけ、内容を言い換えるだけ）
  2. データ収集で使った質問をそのままテーマにする（[[50-Analysis-Methods/20-Literature/LIT-oka-2022-reflexive-ta-ja|岡ほか 2022]] の紹介でも確認）
  3. 弱い、説得力のない分析（テーマが機能していない、テーマ間の重なりが多すぎる、テーマの内部が一貫していない、例が少なすぎる）
  4. データと分析上の主張の不一致
  5. 理論と分析上の主張の不一致、または研究質問とTAの形の不一致
- 良いTAのための15項目のチェックリストを示す（Table 2、PDF p.20）。最初の項目は、データが適切な詳しさで書き起こされ、録音と照合されていること。
- TAの欠点の多くは、方法そのものより、不十分な分析や不適切な研究質問によるとする（PDF p.20）。

## 適用上の注意と限界

- 本論文の6段階の名称は、著者らの後の文献で一部変更されている（[[50-Analysis-Methods/20-Literature/LIT-oka-2022-reflexive-ta-ja|岡ほか 2022]] によれば、第3段階は2018年に「テーマの探索」から「初期テーマの生成」に改名）。
- 著者らは後に自分たちのTAを「再帰的TA」と名付け、他の形のTAと区別している（岡ほか 2022）。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/thematic-analysis/01-Expert|テーマ分析の専門家]]：分析前の判断（テーマの定義、記述の範囲、帰納的か理論的か、意味的か潜在的か、認識論）を分析設定に記録させる。
- 品質確認：5つの落とし穴と15項目のチェックリスト（項目の詳細は岡ほか 2022の表3で確認）を人の確認項目にする。特に、インタビューガイドの質問をそのままテーマにしていないかを確認する。
- 禁止事項：「テーマが浮かび上がった」という受け身の記述をしない。Transformerの意味クラスタをTAのテーマとして扱わない（[実装判断]）。
