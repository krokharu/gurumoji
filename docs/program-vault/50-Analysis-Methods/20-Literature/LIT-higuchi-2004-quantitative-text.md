# 樋口（2004）：テキスト型データの計量的分析

## 研究目的

テキスト型データを計量的に分析する二つのアプローチを検討し、両者を区別したうえで併用する方法を示す（要旨、p.101）。

## 対象データと研究条件

新聞記事や質問紙調査の自由回答など、社会調査で計量的な分析の対象となるテキスト型データを想定する（要旨）。

## 分析手順の要約

- Correlationalアプローチ：多変量解析を応用し、例えばクラスター分析で同じ文書に頻繁に現れる語のグループを見つけて、データ中の主題を探索する（要旨、p.101）。
- Dictionary-basedアプローチ：分析者が指定した基準に沿って語や文書を分類し、計量的に分析する（要旨、p.101）。
- 著者が開発したKH Coderでは、多変量解析でデータを要約する段階では、データに含める語を逐一選ぶような「手作業」を難しい仕様にし、分析者の理論や問題意識による偏りをできるだけ排除する。一方で、語の有無の論理式などで文書にコードを与えるコーディング規則を扱う機能を持つ（3.1–3.2節、p.105）。

## 主要な知見

- コード化をコンピュータで自動化すると、大量のデータでもコード化の基準に揺らぎや恣意性が生じず、その基準を第三者に明示できるため、検証や共同研究が可能になるとする（p.102）。一方、社会学者の理論仮説や問題意識に沿った分析では自動化に限度があるとする（p.102）。
- 二つのアプローチを併用すると、コーディング規則によってデータのどの部分・側面を取り上げたかを第三者が把握でき、批判や検証に耐えるオープンさという意味での客観性（Phillips 1990）を大きく高められるとする。Correlationalアプローチだけでは理論や問題意識を自由に操作化して追究することが難しく、Dictionary-basedアプローチの利点で補えるとする（p.104）。

## 適用上の注意と限界

- 対象は社会調査のテキスト型データで、会話の逐語録やグループインタビュー特有の問題（話者の交替、相互作用）は扱っていない。
- 論じるのはKH Coderの設計であり、Gurumojiの実装はKH Coderの出力と互換ではない。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/quantitative-text-analysis/01-Expert|計量テキスト分析の専門家]]：データ全体を要約する探索の段階と、理論や問題意識を操作化する段階を分けて扱う。
- 品質確認：語の選択やしきい値を結果と一緒に明示する。概念を語で操作化した場合は、その規則を公開できる形で記録する。
- [実装判断] Gurumojiには辞書・規則による自動コーディングの機能はない。研究者のコードブックと手動コードで代替する場合は、自動コーディングを行ったとは表示しない。
