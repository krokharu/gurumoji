# Kitzinger（1994）：フォーカスグループの方法論と参加者間の相互作用

## 研究目的

フォーカスグループとは何か、通常のグループ討論とどう違うか、どう実施し研究に何をもたらすかを紹介する（要旨）。

## 対象データと研究条件

要旨には特定のデータセットの記載はない。医療社会学者を主な読者として想定している。

## 分析手順の要約

要旨の範囲では、分析手順の記載はない。

## 主要な知見

フォーカスグループを1対1の面接や質問紙と必然的に区別する特徴は、研究参加者の間の相互作用であるとし、研究の過程でその相互作用を明示的に探り、活用すべきだと論じる（要旨）。

## 適用上の注意と限界

要旨だけを読んだため、相互作用の具体的な扱い方、実施上の注意は確認していない。
