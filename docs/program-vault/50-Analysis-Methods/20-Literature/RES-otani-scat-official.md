# SCATの情報提供ページ

## 研究目的

SCATの概要、論文、セミナー、使用した研究、FAQ、tipsとpitfallsなどの情報を提供する（ページの説明）。

## 対象データと研究条件

SCATを、おもに観察記録や面接記録などの質的研究のデータの分析手法と説明する。

## 分析手順の要約

ページ上で確認した範囲：

- 〈4〉には、テクストを解釈した「文」ではなく、最大限精緻化した概念（名詞または名詞句）を書き、それを使った文をストーリーラインに書く。〈4〉に文を書くことはpitfallの一つとして挙げられ、体言止めの文も文だと注意している。
- 実際の分析のモデルとしては、2008年の論文より、新しい分析例を載せた2011年の感性工学の論文が適しているとする。

## 主要な知見

SCATを用いた論文が国際誌にも載録されていると紹介している（2022-03-31の改訂時点で41本と記載）。

## 適用上の注意と限界

開発者の情報提供ページであり、査読を経た資料ではない。記載は改訂で変わりうる。

## 専門家の判断・手順に反映する内容
