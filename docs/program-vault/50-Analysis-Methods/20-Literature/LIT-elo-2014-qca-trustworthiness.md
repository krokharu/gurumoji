# Elo et al.（2014）：質的内容分析の信用性

## 研究目的

看護科学の研究で質的内容分析の信用性（trustworthiness）を検討した論文が少ないため、分析の段階ごとに信用性を扱う（要旨）。

## 対象データと研究条件

先行研究の検討、著者らの経験、方法論の教科書に基づく（要旨）。特定のデータセットの分析ではない。

## 分析手順の要約

データ収集から結果の報告までの主要な段階、つまり準備（preparation）、組織化（organization）、報告（reporting）ごとに信用性を記述する（要旨）。

## 主要な知見

- 信用性は、credibility、dependability、conformability、transferability、authenticityなどの語で示されることが多い。
- 分析過程のすべての段階の信用性を精査することが重要で、それらを合わせて研究全体の信用性を読者に示すべきだとする。
- 信用性を高めるための研究者向けチェックリストを作成した。
- データ収集方法や分析の記述が不十分なため、信用性を評価しにくい研究が多いと論じる（要旨）。

## 適用上の注意と限界

要旨だけを読んだため、チェックリストの項目は確認していない。

## 専門家の判断・手順に反映する内容

- [[50-Analysis-Methods/10-Experts/qualitative-content-analysis/01-Expert|質的内容分析の専門家]]：品質確認を準備・組織化・報告の段階ごとに分けて示す。データ収集と分析の手順が記述されていない結果は、信用性を評価できないと表示する。
