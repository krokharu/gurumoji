# モデル別コンテキスト管理と作業記録の保存計画：実装の順序と完了条件

親索引・状態・確認版：[[40-Design/20-Knowledge/model-context-and-work-memory-plan/00-Index]]。必要な本文だけを取得する。

## 実装の順序と完了条件

順序はP0→P1→P2→P3→P4。日数はP0の計測後に見積もり、未計測の性能目標で工数を断定しない。各段階で既存runの読取、盲検、送信条件、進展判定を維持する。

| 段階 | 作るもの | 主な変更候補 | 完了条件 |
| --- | --- | --- | --- |
| P0 現状計測 | 役割別のprompt・schema・入力・履歴の内訳と評価項目 | 既存の試験スクリプト、保存済み台帳の読取 | 先頭48発話の比較対象と全323発話の別試験を固定し、超過・未実行・統合不足を区別 |
| P1 入力予算 | ロードinstance情報、token計測、出力予約、実行前判定 | `services/ai/settings.py`、`services/ai/client.py`、既存adapter | 最終入力全体が予算内。最小入力が入らない場合はAIを呼ばず理由を保存。ロード変更・不明値も検証 |
| P2 必要情報の取得 | 初期ルーティング等の専用契約、段階取得、発話分割、未評価結果の分割 | `analysis_orchestration.py`、adapter、専門知識の既存生成境界、対象スキル | 全量試験で各役割の対象323発話を漏れなく提示。前後文脈の重複計数なし。必須の手法条件と根拠、blind契約を維持 |
| P3 保存と再開 | 取得範囲とパケット来歴、途中の尺度要求、差分要約、公開待ちの回復 | 既存SQLite台帳・checkpoint・成果物保存・Vault生成 | 再起動で保存済み結果を再利用。未処理が消えず、Vault失敗だけで再推論しない。人の編集を保護 |
| P4 モデル評価と導入 | 役割別の合格表、マーラータン比較、新設定の選択導入 | 関連テスト、実AI試験、Software Vaultの運用資料 | 予算・根拠・内容進展の基準を満たした組合せだけ使用。未合格の役割は明示的に保留 |

P2以降の保存情報は、P1から取得条件とID/hashを記録できるようにする。小さい縦切りで導入し、空の共通基盤や全テーブルの作り直しを先行させない。runtime変更にはprompt/packet/config版を付け、旧runを新設定で自動再実行しない。

## 検証方法と採用基準

最初に一時DBと架空の日本語発話で、8K・16K・32K等の設定枠を試験する。これは容量制御の合成試験であり、その枠で実モデルの品質が保証されたことにはならない。実AIは利用可能なモデルごとに、モデル版・量子化・実行設定・prompt・対象集合を固定して比較する。

| 観点 | 必須の確認 |
| --- | --- |
| 入力と出力 | schemaとtemplateを含む入力、出力予約、安全余裕の合計が実ロード枠以下。途中終了を成功にしない |
| 節約効果 | 同じ発話集合・必須条件で比較し、指示・schema・反復履歴のtoken削減を測る。30〜50%削減は試験目標であり未達でも証拠を削って達成扱いにしない |
| 全量と位置 | 323発話のコピーを予算別に分割し、IDの集合で提示範囲を照合。重要な根拠を先頭・中央・末尾へ動かし、対象数・分母・根拠追跡を検証 |
| 初回の尺度 | 全初期役割への依頼、途中要求の永続化、Handler集約、Core指示、専門家作成、保存の順序。定義だけの状態と値付与済みを区別 |
| 反復の中身 | 回数ごとの新しい根拠・結果採否・主張・保留理由・停止理由を表にする。同じ作業案やIDだけの変化を進展にしない |
| 統合品質 | 主張がある場合は根拠本文と対応。主張を出せない場合は入力不足・対立・未完了工程を追跡できる保留理由が必要。3回実行やJSON合格だけで分析完了にしない |
| 再開と競合 | 完了済みタスクの再利用、未評価結果の保持、元hash変更時の再取得、Vault公開失敗からの回復、人の編集保護。応答未保存の実行は状態不明として扱い、成功を仮定しない |
| 情報の分離 | verificationのblind入力、専門知識の承認と送信条件、秘密値の除外、原本DBと研究者Vaultへの試験書込みなし |

課題別の研究妥当性は構文validatorと分けて評価する。根拠のない主張を増やしてCore主張数0件を解消しない。応答待ち・不正応答・未実行を区別し、VRAM・処理時間・総呼出数も実測する。入力削減で呼出数が増える場合は総時間と品質を合わせて判断する。
