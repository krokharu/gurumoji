# Gurumoji 日本語UI文言と状態の仕様案：7 clean v2の読みやすさへの追加批評

親索引・状態・確認版：[[40-Design/30-Interface/ui-microcopy-state-catalog/00-Index]]。必要な本文だけを取得する。

## 7 clean v2の読みやすさへの追加批評

対象は同一fixtureの比較8図＋補助状態2図。今回はSVGの文字列を読み、`a-measurement-390.png`、`b-measurement-changed-390.png`、`b-evidence-390.png`の3図を実画素で確認した。全図の新たな画素再検査、実ブラウザー操作、利用者実験ではない。初回・修正後・今回の確認数を合算しない。

既存の改善で、対象数、入力版、0と欠測、採用と実行の差は見える。ただし「日本語にした」だけで読みやすいとはしない。

| v2で残る読み取りの負担 | 次の比較で試す文言 | 守る条件 |
|---|---|---|
| 「全5発話・除外1 → 試行4」は短いが、矢印を算術として読む必要がある | 「全5発話のうち1発話を除外」「残る4発話を試行」 | 欠測1は試行4の内数で、除外1と足さない |
| 「有効3 / 欠測1」「有効」が、研究上妥当な値の承認に見える余地 | 「算出3発話・欠測1発話」、値の横は「算出済み」 | 統計的な有効性の検証ではない。専門家向け詳細に元の用語を残してよい |
| 「計算済みゼロ」は説明として長く、0秒の横に別カテゴリのように出る | 値は「0秒」、状態は「集計に含む」 | 通常の0行と欠測行を分け、平均へ含む説明は保持 |
| 「発話の秒数 / 数値 / 比率尺度 / 記述統計」は等しい重みの専門語が並ぶ | 主文「発話ごとの時間を秒で集計」＋「平均を算出」、型・尺度・入力列は詳細 | durationは現行の保存済みduration値を使う。開始・終了から常に再計算するように言い換えない。規則の限界は主文の近くに残す |
| A mobileの「設定・手動分析」は測定設定なのかコード付けなのか残る | 場所は「測定の設定」、既存モード名を残すなら「設定・コード付け › 測定」 | 先にIAを全面変更せず、同じ作業の局所的な題名で比較 |
| 「原資料・分析時の本文」は、録音原本または未編集逐語録と読める | 「分析時の発話本文」 | 保存された発話版だと伝える。原音との照合済みを含意しない |
| 「AI下書き・未確認」「研究者メモ・未確定」は誰の何が未確認か曖昧 | 「AI下書き」を基本にし、記録がないと確かめられる場合だけ「確認記録なし」。メモは保存状態と解釈の確定状態を別表示 | 読取不能と記録なしを分ける。測定レビューやAI見解の確定recordを新規保存したことにしない。研究者が未読だと断定しない |
| S004のリンク名「発話を確認」は他行と並ぶと識別しにくい | 「S004の試行時の入力を確認」 | 実際に固定試行入力へ到達できる契約後だけ。現在本文を代用しない |
| 無効な「この定義を採用」「音声で確認」が淡いボタンで残る | ボタンの目的名は維持、隣に「再試行が必要」「引用と現在の発話を照合できないため再生できません」 | disabledをATへ伝え、理由を関連付ける。曖昧な「利用不可」だけにしない |
| B mobileの「結果のメモを見る」は根拠を読む作業から離れた所にある | 主張の下に「研究者メモあり」と短く示し、同一文脈で開く候補を比較 | A/Bの全長差を理解の改善へ換算しない。メモへ戻る負担を比較課題へ含める |

上記は文言・情報位置の仮説であり、v2の新規欠陥件数ではない。390pxでは「平均から除いています」が改行をまたぐが、文字欠けを認めたわけではない。文を短くしても欠測の説明を消さない。「重要性や関与の強さは表しません」は短くても意味のある限界なので保持する。
