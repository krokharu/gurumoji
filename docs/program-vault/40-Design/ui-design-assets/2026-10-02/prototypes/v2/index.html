判断項目をそろえて比べる

測定では、①規則が秒数か、②入力と4値が対応するか、③0/欠測の集計、④内容を採用してよいか、⑤採用と実行は別か、の5判断を両案に残しています。Aは定義へ戻るか採用、Bは同じ面で再試行か採用を判断します。Bの編集後は旧試行を無効にする状態が必要です。

根拠では、①AI/研究者/原資料の区別、②現在音声へ進んでよいか、③同じ結果へ戻れるか、の3判断を比較します。B mobileには主張と限界を残し、メモだけ詳細へ移しています。図が短いことを、そのまま利用者の負担が減った証拠にはしません。

図の全長pxやbutton数は、実測の速度・認知負担・使いやすさスコアではありません。構造上はAを小さく導入し、Bの対照面・根拠pane・4タスクnavを別々に検証する提案を維持します。

画面外の番号付き凡例

以下は設計レビュー用の注釈です。通常の利用者画面へ常時出す文言ではありません。

M1 定義と詳細

通常は日本語の規則・型・尺度・手法を表示。IDや英語enumは詳細へ。採用済み定義は別draftで保護する提案であり、現行にimmutable履歴があるとは主張しません。

M2 個票と欠測

個票ID・理由・定義revisionは現行trial応答にないため追加が必要。時刻も同じtrial snapshotから解決し、最新データに結合しません。0・欠測・除外を分けます。

M3 採用と変更

試行→明示採用→別の全件実行確認。定義/入力変更で旧試行を無効化します。実行版の固定または不一致停止は必須。画面checkboxを永続レビュー保証とは扱いません。

M4 実行範囲

外部送信なしはこの基礎測定の説明。O01、Transformer、AI見解の個別実行は別経路で、一括モデル起動を約束しません。

E1 保存済み結果

結果#07は合成run R-demo-07。固定viewerと完全な復帰は未実装の提案。固定artifact読取と、回復を起こし得るpipeline status取得を分けます。

E2 内容の帰属

AI未確認、研究者未確定、分析時原資料を文字で区別。根拠1発話と前後文脈を混同しません。B mobileにも主張と解釈の限界を残します。

E3 本文変更と再生

現在の発話を別表示する操作は提案。旧引用を置換せず、対応を確認できない音声は再生しません。元発話への確実な対応がなければbuttonを有効にしません。

E4 復帰

同じitem/run/page/filter/引用/scroll/focusへ戻る契約を既存navigation stateへ対応付ける提案。図のClose/Backは動作しません。

アプリ・runtime・Vault・資格情報の変更、外部公開、pushは行っていません。ローカルの自己完結HTMLとSVGで、外部通信やスクリプトはありません。
