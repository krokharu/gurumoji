# Gurumoji 研究作業シナリオと受入条件：S07 日本語の長い発話を狭い画面で確認し保存する

親索引・状態・確認版：[[50-Tests/30-Interface/ui-design-scenarios/00-Index]]。必要な本文だけを取得する。

## S07 日本語の長い発話を狭い画面で確認し保存する

**研究者の仕事:** 長い発話の話者名と誤変換を直し、保存後に統計のページへ進む。別ケースで話者を追加する。

**入力:** 長い氏名・ファイル名、複数段落の日本語、英数字混在、同名話者、多数の分析tab、0件／1件／多数件の一覧、検索0件と全件欠測。対応: DG-07/08/12/14、W08。

1. 390pxと320px相当で、選択発話を開き、原音と本文を照合する。再生中の発話、編集中の選択、保存した引用を区別し、追従を止めても選択を失わないことを確認する
2. IMEで変換し、確定して保存する。変換中に単キーshortcutが走らないことを確認する
3. 保存barとkeyboard表示の間で必要なcontrolを操作し、成功／競合を確認する
4. 右端の分析ページを選び、現在のページ名とfocusがnav内で見えることを確かめる
5. 根拠へ移って戻り、画面幅変更・Back/Forward・reduced-motionでも位置を確認する
6. 話者追加後に次の入力が見えるか確認し、空状態から次の作業へ進む

**受入:** document幅のoverflowがないだけで合格にしない。navの選択labelとmain nav現在地、入力focus、保存feedbackが読める。採用disabledとその理由も色以外の表示・役割・状態で分かる。固定heightによる文字切れなし。text-spacing上書きや200%拡大で機能が失われない。必要な表は領域内scrollと代替表等を保ち、周辺操作はreflowする。v2のMC-07はこの実UI確認へ引き継ぐ。

**比較:** 現行と候補の同じ内容・状態・幅を比べる。主作業到達までのscroll／操作、読み違い、保存誤認を記録する。フォント拡大で全情報を縦に長くする案と、列優先・詳細開閉を使う案のtradeoffを確認する。安全説明を隠して短くする案は採用しない。

## 回帰で必ず残す既存の保護

上記シナリオの変更箇所に応じて原UI-01〜10とA01〜14/V01を再実行する。全シナリオに全試験を機械的に付けず、境界を跨ぐ保護は漏らさない。

- 未保存移動、連打、古いresponse、別対象への移動、中止と完了の競合
- 削除Undo、保存409、未保存draftの書出し、CSV previewの取消
- 計算済みゼロ／欠測／未計算、対象集合・分母、本文版・model版の来歴
- 生成ノートの研究者編集保存、競合、Vaultのみretry、実Vaultを試験に使わない
- 閲覧と実行を分け、未承認の外部送信・モデル取得を試験の裏で始めない

## 利用者比較を行う場合の判定

初回利用者と反復編集者、質的研究経験者、必要なAT利用者の課題を区別する。人数を万能な固定数から決めず、重大な誤認を検出する形成的試験として計画する。比較順と等価fixtureを入れ替え、学習効果を抑える。

主指標は正しい対象・版での完遂、編集保持、誤測定と根拠不一致の発見、回復成功。時間・遷移数・負担は補助。採用前の停止条件は、重大な誤測定、保存損失、外部送信誤認、引用取り違えが候補UIで生じること。発見したら該当案を修正し再確認する。少人数の比率や平均時間を一般的な生産性向上率へ拡大しない。

第4稿時点の結果: 全シナリオは仕様として作成。V3/V4/V5は未実施。clean v2の静止レビューはアプリのV1〜V5成功数へ加えない。DG-01/02/03等の現行不整合は別のソース／隔離probeによる証拠を持ち、[独立反証](../../ui-design-evidence/2026-10-02/adversarial-checks.md)へ戻れる。追加の送信／保存／handler合成probeも、本シナリオ全体や改修の成功を意味しない。短い表示文は[文言仕様](../../../40-Design/30-Interface/ui-microcopy-state-catalog/00-Index.md)の成立条件と一緒に使う。
