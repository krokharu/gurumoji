# AI見解の根拠参照番号・GPT-OSS回帰チェックリスト

実施状況：すべて未実施。ユーザー指定により、今回の変更では自動テスト、アプリ再起動、モデル呼び出し、実データ再分析を行わない。

対象：`src/gurumoji/analysis_insights.py`、`src/gurumoji/app.py`の`call_ai_json`。参照：[[../50-Analysis-Methods/06-Generative-and-Workflow/01-AI-Insights|AI見解・下書きの実装契約]]。

## 1. モックによる参照の整合性

- [ ] 架空の32文字の発話IDを複数用意し、AI入力の`id`が`E0001`等になり、元のIDが識別子としてプロンプト／schemaに含まれないことを確認する。
- [ ] 短い参照番号で回答させ、最終`segment_ids`・`speakers`・`count`が元の発話に正確に戻ることを確認する。元の入力データが変更されないことも確認する。
- [ ] 各呼び出しのschemaの`enum`が、そのバッチにある番号だけを含み、隣接バッチ・除外発話・空白発話の番号を含まないことを確認する。
- [ ] 1発話を複数断片に分けても同じ番号を使い、末尾の文章まで入力に残ることを確認する。
- [ ] 多段階の統合で番号が再割り当てされず、各グループの根拠と話者対応が一致することを確認する。
- [ ] 元のID、`05`、`09`、`SPEAKER_05`、未知の`E9999`を回答に入れても、補完・推測変換せず拒否することを確認する。
- [ ] 空の根拠配列、文字列型の根拠、数値／null／オブジェクトの要素を区別して拒否し、エラーに項目位置が出ることを確認する。
- [ ] 同一話者の発話2件を`shared`として返すと拒否し、異なる話者の有効な発話2件なら通ることを確認する。
- [ ] 同じ番号の重複は元のIDへ復元後も重複しないことを確認する。

## 2. 修正再試行・停止

- [ ] 初回が不正、2回目が正しい回答なら成功し、再試行の進捗表示とトークン使用量が更新されることを確認する。
- [ ] 再試行の入力に、具体的な検証エラーと不正項目の抜粋が含まれ、抜粋が最大2項目に制限されることを確認する。
- [ ] 再試行でも不正なら追加の呼び出しをせず失敗とし、途中までの結果を保存しないことを確認する。
- [ ] 初回呼び出し前、再試行前、統合中、保存前のキャンセルを確認する。
- [ ] 接続失敗・不正JSON・統合が縮小しない場合に、成功や完了として表示されないことを確認する。

## 3. トークン上限・モデル互換性

- [ ] LM Studioの`finish_reason=length`をモックし、「トークン上限で途中終了」と表示され、通常の不正JSONと区別できることを確認する。使用量は保持する。
- [ ] `finish_reason=stop`で正常JSON、不正JSONの両方を確認する。OpenAI／Geminiの通常応答に影響がないことも確認する。
- [ ] 入力だけでなく統合対象も6,000文字の目安で分割されることを確認する。
- [ ] GPT-OSS 20BとQwenで、動的`enum`・`minItems`・`maxItems`を含むschemaが受理されることを確認する。非対応時に制約を黙って外さないことを確認する。
- [ ] 短い架空データでGPT-OSSの1バッチを先に確認する。モデルID、推論強度、コンテキスト長、終了理由、入出力トークン数を記録する。
- [ ] 複数バッチと統合を含む実行で、schema・再試行用の抜粋も含めて出力の余裕があることを確認する。6,000文字はトークン数の保証ではない。

## 4. 保存・Obsidian・後日の全件実行

- [ ] 再起動前に対象の既存結果をバックアップする。実行中のジョブがないことを確認して修正版を読み込む。
- [ ] `content-insights-2`の既存結果が保持され、版変更で古い結果として表示されることを確認する。自動でLLMを起動しないことを確認する。
- [ ] 成功時のDB、アーカイブJSON、CSV、Obsidian根拠リンクにAI入力専用番号が保存されず、元の発話IDを使うことを確認する。
- [ ] source_revision／analysis_revision競合時と保存失敗時に、既存の成功結果を保持することを確認する。
- [ ] GPT-OSSで対象会話の全435発話を処理し、入力カバー範囲、統合完了、保存完了、根拠リンクを確認する。
- [ ] Obsidianで「分析種類 → 結果」のノードと、結果から原文へのリンクを確認する。AI見解が原文に支持されるかは人が読む。

