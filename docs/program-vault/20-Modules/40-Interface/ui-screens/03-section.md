# Web UIの画面構成と既存機能の対応：既存機能の移動先

親索引・状態・確認版：[[20-Modules/40-Interface/ui-screens/00-Index]]。必要な本文だけを取得する。

## 既存機能の移動先

| 既存機能 | 旧画面の場所 | 新しい場所 |
| --- | --- | --- |
| APIトークンの状態、使用モデルの選択 | ヒーロー右側のトークンパネル、スマホは新規作成ヘッダー | 上部バーのトークン表示（1321px以上）と「接続と処理装置」ダイアログ |
| マシン診断、CPU/GPUの利用可否 | ヒーロー、認識設定のマシン診断、スマホヘッダーの3か所 | 「接続と処理装置」ボタンのCPU/GPU表示とダイアログ。自動設定の内容は「認識・話者分離」の先頭 |
| 会話モード（会議／グループインタビュー／雑談） | 新規作成01 | ステップ2「設定を確認する」の先頭 |
| ファイル選択、ドラッグ＆ドロップ、パス・保存先 | 新規作成02 | ステップ1。パス・保存先は折りたたみ |
| 認識モデル、言語、前処理、小声対策、詳細処理、処理装置、話者数、VAD | 新規作成03（詳細設定の一部は常時表示） | ステップ2の「認識・話者分離」パネル（閉じた状態） |
| 単語登録 | 新規作成03（常時表示） | ステップ2の「単語登録」パネル |
| AI仕上げ、Obsidianで仕上げ、思考モードとエフォート | 新規作成04（エフォートは常時表示） | ステップ2の「AI仕上げ」パネル。エフォートはその中の折りたたみ |
| 音声感情分析 | 新規作成05 | ステップ2の「音声感情分析」パネル |
| 出力形式（SRT、字幕付き動画） | 新規作成06 | ステップ2の「出力形式」パネル |
| 開始、設定要約 | 開始バー、左ナビの要約、スマホの確認一覧 | ステップ3「内容を確認して開始する」 |
| 進捗、トークン使用量、システム使用状況、処理ログ、中止 | どの画面でも表示される進捗カード | 新規作成画面の進捗カード。ほかの画面では上部バーのチップ |
| 処理済みデータ一覧 | 上部バー「処理済みデータ」 | 上部「文字起こし結果」と結果領域の補助ナビ「データ一覧」 |
| 分析・可視化、比較 | 上部バー「分析・可視化」 | 上部「分析・可視化」と結果領域の補助ナビ。比較は分析内 |
| データグループの作成・割り当て・グループ順表示 | なし（新規） | 「処理済みデータ」のグループ管理、カードのグループ選択、絞り込み・並べ替え |
| 発話の再生・編集・追加・削除、絞り込み | 1ページの結果画面の下部 | 作業画面「発話の確認・編集」。デスクトップはプレイヤーを左に固定 |
| 会話プロファイル、会話話者連携、話者名のAI再特定、会話話者CSV | 結果画面の中段 | 作業画面「会話・話者」 |
| 会議議事録・タスク、アウトライン、感情の要約、AIトークン使用量 | 結果画面の上段 | 作業画面「議事録・アウトライン」 |
| 予定した議題（質問ガイド）と、実際に話された内容の時間順一覧 | なし（新規） | 作業画面の見出し直下「アウトライン（予定と結果）」。折りたたみ可。要点は「議事録・アウトライン」タブ |
| ダウンロード、実行フォルダー、データの削除 | 結果画面の見出し、下部の危険操作エリア | 作業画面「ファイル・管理」 |
| 編集内容を保存、Obsidianで仕上げ | 固定バー（一覧へ戻る・分析と同居） | 作業画面下部の保存バー（2つだけ） |
| 一覧へ戻る、分析・可視化、話者管理への移動 | 関連画面ナビと固定バーの2か所 | 作業画面の見出し（「← 処理済みデータ」「分析・可視化 →」）と上部バー |
| 空のデータを追加、話者管理、事前アンケート分析 | 変更なし | 変更なし |
