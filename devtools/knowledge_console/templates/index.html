対象の知識を確認する

目標に必要なノートを選択し、読んで確認した内容を記録します。整理は重複・矛盾・出典の3項目。深さは根拠や適用条件で判断し、文字数では測りません。ノートを編集すると、その確認記録は再確認が必要になります。

想定質問と検索テスト

質問・検索語・到達したいノートを固定して比較します。対象ノートのタイトルと本文を検索語のAND条件で検索し、必要なノートがすべて上位5件に入れば成功です。これはこの画面の検索テストで、Obsidian本体の検索や意味検索の評価ではありません。

3. ノートからタスクを生成

参照するノートを1〜3件選択します。選択した抜粋をローカルLLMへ渡し、目標に向けたタスクを下書きとして追加します。A100で実行すると同じ抜粋がColabに渡ります。

この目標から生成したタスク

成果物の総合評価

実際に生成に使ったプロンプトと成果物を入力してください。上の参照ノートから選択した1〜3件を根拠として、ローカルLLMが「目標の充足・根拠・一貫性・再利用性」を各25点で評価します。タスク採点とは別の評価です。

          接続設定

          上から順に進めます。済んだ手順には✓が付き、次回からは4だけで接続できます。

          Google Colaboratory: Workerノートブックを開く ↗ / Colabトップ ↗

          1. 1. OAuthクライアントJSON (初回のみ) Google Cloud ConsoleでDrive APIを有効にし、「デスクトップアプリ」のOAuthクライアントを作ってJSONをダウンロードします。 Cloud Consoleを開く ↗
          2. 2. Google Driveを認可 (初回のみ) ブラウザにGoogleの許可画面が開きます。Colabと同じアカウントを選んでください。
          3. 3. Workerノートブックを反映 (更新時のみ) このPCの最新版WorkerをDrive上のノートブックへ上書きします。
          4. 4. ColabでWorkerを実行 ランタイムでA100を選び「すべて実行」。起動状況は5分ごとに自動確認し、「接続確認」ですぐに確認できます。
